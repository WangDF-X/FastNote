## 1. 目的与范围

定义设置中心的整体信息架构和导航结构。所有配置项按功能分组展示在侧边栏式布局中，用户可逐组查看和修改。确保设置页的可发现性和一致性。

**范围内**: 分组结构、导航方式、搜索框（v1 无）、页面标题切换。
**范围外**: 具体设置项内容（SET-02 / SET-03）。

## 3. 页面结构

```text
设置                        ← 页面头部标题
│ 通用与外观                ← 当前分组高亮（左侧 accent bar）
├── 全局快捷键               │
├── 任务偏好                 │
└── 关于                     │
                             │
          [返回]              ← 回到进入设置前的页面
```

## 4. 保存策略

| 类型 | 保存行为 |
| --- | --- |
| 一般设置（主题、入口模式等） | 即时保存到 `app_meta.json` |
| 全局快捷键 | 注册后立即生效 + 写入设置 |
| 任务偏好 | 即时生效并刷新 Today 视图 |

- 不需要「保存」按钮；所有修改即时持久化。
- 保存失败时 inline error + Toast 错误提示。

---

## 5. 返回行为

从设置页返回时恢复进入设置前所在的页面路由和会话状态（滚动位置、选中日期等）。
