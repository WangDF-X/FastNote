## 1. 目的与范围

定义用户个性化偏好的配置项：入口模式、主题、窗口默认大小、悬浮球尺寸与透明度、周起始日等。确保每个设置修改都能即时反馈且不破坏用户体验。

**范围内**: 入口模式、主题切换、周起始日、悬浮球参数、关闭行为。
**范围外**: 快捷键绑定（SET-03）、数据管理（DATA-xx）。

## 3. 设置项详解

### 3.1 入口模式

| 字段 | `general.entry_mode` |
| --- | --- |
| 类型 | 单选（Radio Group） |
| 选项 | `ball`（默认）/ `tray` / `none` |
| 说明 | 决定应用驻留在桌面的方式 |

- 切换后立即生效（销毁旧入口 → 创建新入口）。
- `none` 表示不显示任何常驻入口（仅主窗口可用）。
- 如果当前平台不支持所选模式，显示 warning tooltip 并自动回退到可用的下一个模式。

### 3.2 主题

| 字段 | `general.theme_mode` |
| --- | --- |
| 类型 | 单选（Segmented Control） |
| 选项 | `system`（默认）/ `light` / `dark` |
| 说明 | `system` 跟随系统亮度设置 |

- 切换后全局即时生效。
- `system` 模式下通过 platform API 监听系统主题变化事件。

### 3.3 悬浮球参数

| 字段 | 类型 | 默认值 | 范围 |
| --- | --- | --- | --- |
| `ball.size` | Int (px) | 48 | 32 – 96 |
| `ball.opacity` | Float (0.0–1.0) | 0.85 | 0.3 – 1.0 |

- `ball.size`：滑块控件，步长 4px，实时预览。
- `ball.opacity`：滑块控件，拖动时实时预览效果。

> **已确认（2026-10-26）Q-SET-03：** 悬浮球尺寸上限 96px 是否足够？→ **当前默认处理：** 保持 ARCH-05 定义的 32–96 范围不变；如果需要更大在 v2 评估。

### 3.4 关闭窗口行为

| 字段 | `general.close_behavior` |
| --- | --- |
| 类型 | 单选 |
| 选项 | `entry`（隐藏主窗口保留驻留）/ `quit`（退出应用） |
| 默认 | `entry` |

> **已确认（2026-10-26）Q-SET-04：** close_behavior=quit 是否需要额外提示或确认？→ **当前默认处理：** 不需要——该设置在设置页中有清晰描述性文本说明其后果，用户可直接选择。

### 3.5 周起始日

| 字段 | `general.week_starts_on` |
| --- | --- |
| 类型 | 单选 |
| 选项 | `Monday`（默认）/ `Sunday` |
| 说明 | 影响日历视图的列顺序 |

- 修改后立即刷新所有日历页面。

## 4. UI 呈现细节

### 4.1 滑块控件

| 属性 | 值 |
| --- | --- |
| 高度 | 32px |
| 轨道颜色 | `bg.subtle` |
| 填充颜色 | `accent` |
| 拖拽手柄 | 圆形 16px + `accent` |
| 数值标签 | 滑块右侧或上方显示当前值 |
| 最小/最大 | 轨道两端标注 |

### 4.2 透明度预览

拖动 opacity 滑块时，实时在背景上叠加一个半透明色块预览效果：

- 滑块在 1.0 时预览色块为不透明。
- 滑块接近 1.0 但仍低于时，预览色块正常显示（不闪烁到不透明）。

> **已确认（2026-10-26）Q-SET-05：** 透明度滑块拖动到接近 100% 时的预览问题？→ **当前默认处理：** 预览始终显示新值，即使拖动到非常接近 100% 仍显示对应的透明度效果。
