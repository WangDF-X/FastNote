## 1. 目的与范围

定义用户个性化偏好的配置项：入口模式、主题、窗口默认大小、悬浮球尺寸与透明度、周起始日等。确保每个设置修改都能即时反馈且不破坏用户体验。

**范围内**: 入口模式、主题切换、周起始日、悬浮球参数、关闭行为。
**范围外**: 快捷键绑定（SET-03）、数据管理（DATA-xx）。

> **本轮 Windows 范围（2026-11-02 用户确认）：** 在已有 `general.entry_mode`（ball/tray）与 `general.close_behavior` 基础上接入主题三态、持久化、系统变化监听，以及主窗/悬浮球/入口菜单的统一配色。主题键统一为 ARCH-04 已有的 `appearance.theme`，不创建 `general.theme_mode`。通用页继续只读展示唤起热键注册状态；密度、悬浮球参数、周起始日等仍不在本轮。

> **2026-11-03 用户确认的最终修订：** 主题入口位于左侧栏「设置」行的右侧，使用单格图标按钮，不显示文字说明。点击按 `system → light → dark → system` 循环，当前偏好分别用系统/太阳/月亮图标表示；不在通用设置页重复放置。深色时侧边栏品牌图标、标题栏和悬浮球使用已有 `fastnote-app-icon-reversed.svg`；浅色还原彩色版。任务栏、Alt+Tab、托盘及 exe 文件图标保持原样，不重新设计或生成品牌资产。

> **2026-11-07 日历范围补充确认：** 本次加入周起始日设置入口，统一使用既有 `appearance.week_starts_on`；默认 `monday`，可选 `sunday`，修改持久化并立即刷新日历。其它原先排除的设置不受影响。

## 3. 设置项详解

### 3.1 入口模式

| 字段 | `general.entry_mode` |
| --- | --- |
| 类型 | 单选（Radio Group） |
| 选项 | `ball`（默认）/ `tray` |
| 说明 | 决定应用驻留在桌面的方式 |

- 切换后立即生效（销毁旧入口 → 创建新入口）。
- 球模式下主窗与球互斥：主窗可见时切到球模式不立即显示球，最小化/隐藏主窗后才显示。托盘模式图标仍可与主窗共存。
- 不提供 `none` 选项；仅当两个入口都失败时临时保留主窗口，并将有效关闭行为降级为退出，不改写用户配置。
- 如果当前平台不支持所选模式，显示 warning tooltip 并自动回退到可用的下一个模式。

### 3.2 主题

| 字段 | `appearance.theme` |
| --- | --- |
| 类型 | 左侧栏「设置」行右侧的 36×36 单格图标按钮，点击循环三态 |
| 选项 | `system`（默认）/ `light` / `dark` |
| 说明 | `system` 跟随系统亮度设置 |

- 成功加入保存队列后立即预览新主题，不等待 SQLite 写入；保存失败恢复原主题并显示既有中文存储错误，不把预览当作已保存。
- 主窗口、Slint 标准控件、悬浮球及其自绘菜单同步切换；隐藏后重新显示和重启均保持正确主题。侧边栏品牌图标、标题栏和悬浮球按实际深浅色切换已有彩色/反色资源，不手工反转像素或重新生成资产；其它图标位置保持原样，原生托盘菜单由 Windows 绘制。
- 左侧栏的主题按钮在所有页面可见，与「设置」同处一行、垂直居中，只显示当前偏好的图标，不显示文字、分段选项或说明行。设置项宽度收缩，二者点击区域不重叠。系统模式始终显示系统图标，即使其有效配色为深色，避免与手动深色混淆。
- 点击以及焦点上的 Enter/Space 按既有选项顺序 `system → light → dark → system` 轮换；顺序由 core 的纯规则决定，UI 只发出循环动作。保留不可见的中文无障碍标签和实际焦点，焦点框按 ARCH-05 D-TODAY-07 关闭，图标不因残留焦点持续染成蓝色。
- 保存中、设置未加载、不可写或模态对话框打开时禁用。系统读取失败仍按既有逻辑回退浅色，不在按钮旁添加说明文字。
- `system` 模式读取 Windows 的 `AppsUseLightTheme`，通过隐藏的原生通知窗口监听 `WM_SETTINGCHANGE`；监听窗口随应用释放，不增加线程或轮询。读取失败回退浅色，手动亮/暗仍可用；监听失败时使用窗口主题事件及重新显示/获得焦点时核验。
- 手动选择 `light` / `dark` 时系统变化不得覆盖用户选择；回到 `system` 时重新读取系统当前值。
- 标题栏采用 SHELL-01 §3.1 的轻量自绘方案；Slint 内置 `Palette.color-scheme` 同步实际主题，避免标准滚动条残留另一套亮/暗状态。

**依赖决策（2026-11-03 更新）：** 复用 `windows` 与 Slint/winit，仅为现有 `windows` 开启注册表和窗口子类化 API 所需特性，不新增 `dark-light` 或其它 crate。额外常驻窗口资源为一个不可见通知 HWND；无新增后台线程、异步运行时或定时轮询。品牌图标资产不变，仅新增四个标题栏操作 SVG 及三个主题状态 SVG。许可证与现有依赖一致；二进制体积及运行时资源增量未实测。

### 3.3 悬浮球参数

| 字段 | 类型 | 默认值 | 范围 |
| --- | --- | --- | --- |
| `ball.size` | Int (px) | 48 | 32 – 96 |
| `ball.opacity` | Float (0.0–1.0) | 0.85 | 0.3 – 1.0 |

- `ball.size`：滑块控件，步长 4px，实时预览。
- `ball.opacity`：滑块控件，拖动时实时预览效果。

> **已确认（2026-10-26）Q-SET-03：** 悬浮球尺寸上限 96px 是否足够？→ **当前默认处理：** 保持 ARCH-05 定义的 32–96 范围不变；如果需要更大在 v2 评估。

### 3.4 关闭窗口行为

| 字段 | `general.close_behavior` |
| --- | --- |
| 类型 | 单选 |
| 选项 | `entry`（隐藏主窗口保留驻留）/ `quit`（退出应用） |
| 默认 | `entry` |

> **已确认（2026-10-26）Q-SET-04：** close_behavior=quit 是否需要额外提示或确认？→ **当前默认处理：** 不需要——该设置在设置页中有清晰描述性文本说明其后果，用户可直接选择。

### 3.5 周起始日

| 字段 | `appearance.week_starts_on` |
| --- | --- |
| 类型 | 单选 |
| 选项 | `monday`（默认）/ `sunday` |
| 说明 | 影响日历视图的列顺序 |

- 修改后立即刷新所有日历页面。

## 4. UI 呈现细节

### 4.1 滑块控件

| 属性 | 值 |
| --- | --- |
| 高度 | 32px |
| 轨道颜色 | `bg.subtle` |
| 填充颜色 | `accent` |
| 拖拽手柄 | 圆形 16px + `accent` |
| 数值标签 | 滑块右侧或上方显示当前值 |
| 最小/最大 | 轨道两端标注 |

### 4.2 透明度预览

拖动 opacity 滑块时，实时在背景上叠加一个半透明色块预览效果：

- 滑块在 1.0 时预览色块为不透明。
- 滑块接近 1.0 但仍低于时，预览色块正常显示（不闪烁到不透明）。

> **已确认（2026-10-26）Q-SET-05：** 透明度滑块拖动到接近 100% 时的预览问题？→ **当前默认处理：** 预览始终显示新值，即使拖动到非常接近 100% 仍显示对应的透明度效果。
