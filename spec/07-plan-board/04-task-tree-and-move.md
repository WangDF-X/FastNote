## 1. 目的与范围

定义计划详情页中任务的树形结构展示与层级管理：父子关系的表示、缩进规则、添加子任务的入口、任务的拖拽移入移出，以及跨阶段/跨计划的移动限制。确保用户能够灵活组织复杂项目的任务层级。

**范围内**: 树形渲染、缩进、层级操作、移动规则。
**范围外**: 依赖关系（PLAN-05）、多任务批量操作（v1 无）。

## 3. 树形渲染规范

### 3.1 缩进规则

| 层级 | 左缩进 |
| --- | --- |
| Plan 根（无 parent） | 0px |
| Stage 头（kind=Stage） | 0px |
| Stage 内的第一层任务 | 24px |
| 第二层子任务 | 48px |
| ... | 每层 +24px |

最大缩进到 5 层后停止增长（限制为 5 级深度），超深时最后一层的图标变为 `…`。

### 3.2 行结构

```text
├── ⚪ 任务标题                  ← 圆形复选框 + 缩进 + 标题
│   ├── ◯ 子任务 A               ← 有子任务时的展开箭头
│   └── ◯ 子任务 B
├── ⚪ 另一个任务
```

- 每个任务行显示：复选框（未完成为空心圆，已完成为实心勾）+ 任务标题 + 日期标签（如设置了 due_date）+ 「⋮」菜单。
- 有子任务的任务右侧显示折叠箭头 (`▶` / `▼`)。

### 3.3 完成状态继承

遵循 ARCH-03 的完成状态规则：
- 叶子任务完成后不影响父任务（父任务仍保持自己的状态）。
- 但父任务的进度条反映所有叶子任务完成率。

## 4. 任务操作

### 4.1 在阶段内添加任务

每个阶段的底部显示「+ 添加任务」按钮 → 行内输入框 → Enter 创建。

### 2. 作为子任务添加

在父任务行右侧的「＋」图标 → 将新任务插入为该父的子节点。

### 3. 任务移动

通过「⋮」菜单 → 「移动到…」 → 弹出选择器：

| 目标类型 | 说明 |
| --- | --- |
| 同一计划的其他阶段 | 从当前阶段移出，进入目标阶段 |
| 计划根（取消归属） | 任务移出当前阶段，直接属于计划 |
| 另一计划 | Dialog 确认 → 确认后移动并处理依赖冲突 |

### 4. 跨计划移动

> **已确认（2026-10-26）Q-PLAN-09：** 是否支持多选多个任务批量移动或删除？→ **当前默认处理：** 不支持（v1 仅单任务操作）。

> **已确认（2026-10-26）Q-PLAN-10：** 是否允许拖拽任务到另一个计划的卡片上实现跨计划移动？→ **当前默认处理：** 不支持；跨计划移动通过对话框选择目标计划实现。

### 5. 复制/剪切/粘贴

> **已确认（2026-10-26）Q-PLAN-11：** 是否需要任务级别的复制、剪切、粘贴功能？→ **当前默认处理：** 不需要，复制内容的需求可以通过小记转任务解决。

## 5. 移动约束

### 5.1 禁止循环

| 场景 | 行为 |
| --- | --- |
| 移动到自身或其祖先节点下 | inline error「不能将任务移到自身或上级下」 |
| 移动到自身的子节点下 | inline error「不能创建循环依赖」 |

### 5.2 计划边界

| 移动方向 | 允许 | 条件 |
| --- | --- | --- |
| 同计划内不同阶段 | ✅ 无需确认 | — |
| 跨计划 | ⚠️ 需确认 Dialog | 如果有依赖关联到原计划的任务则提示解除 |

---

## 6. 删除链确认

| 操作 | 确认内容 |
| --- | --- |
| 删除有子任务的父任务 | Dialog「删除 N 个任务？」（含子树数量） |
| 删除阶段（保留任务） | Dialog「N 个任务将移到计划根」 |
| 删除阶段（级联删除） | 用户在菜单中选择「连带删除任务」选项 |
