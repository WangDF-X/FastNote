## 3. 创建计划

### 3.1 入口

- 今日页底部「+ 新建计划」按钮。
- 计划板列表底部「+ 新建计划」按钮。
- `Primary+N`（在计划板页面时）打开新建对话框。

### 3.2 对话框内容

```text
┌───────────────────────────────────┐
│ 新建计划                          │
│                                   │
│ 名称 [_________________________]  │ ← 必填
│                                   │
│ 开始: 2026-10-23         🔘       │ ← 可选
│ 结束:                             │ ← 可选
│ ┌───────────────────────────────┐ │
│ │        选择日期...             │ │
│ └───────────────────────────────┘ │
│                                   │
│         [取消]    [创建]          │
└───────────────────────────────────┘
```

- 名称必填，最大 100 字符。
- 开始/结束日期可选；都留空时视为无期限计划。
- 如果同时填写了开始和结束日期，需满足 `start_date <= end_date`。

### 3.3 创建后行为

创建成功后返回计划列表视图，不自动进入详情面板。新创建的卡片高亮 600ms 以提示用户。

> **已确认（2026-10-26）Q-PLAN-03：** 计划名称冲突时使用相同的错误码（如 `E_NAME_DUPLICATE`）但在不同上下文中是否只改变展示文案？→ **当前默认处理：** 复用同一个错误码但根据上下文（新建 vs 重命名）显示不同的中文提示文本。

> **已确认（2026-10-26）Q-PLAN-04：** 创建完计划后是否自动跳转到该计划的详情页？→ **当前默认处理：** 不跳转，留在列表页并高亮新行；用户需要时可点击卡片进入详情。

## 4. 编辑计划

从计划卡片右上角「⋮」菜单 → 「编辑」打开编辑对话框（结构与新建相同，预填现有值）。

| 可编辑项 | 约束 |
| --- | --- |
| 名称 | 必填，最大 100 字符，不能全空格 |
| 开始日期 | 可选；修改后影响健康度计算 |
| 结束日期 | 可选；必须 ≥ start_date（如果 start_date 非空） |

编辑后即时保存成功。

## 5. 归档与删除

### 5.1 归档

将计划标记为已归档（`archived = true, status = Archived`）。

| 条件 | 行为 |
| --- | --- |
| 计划所有任务已完成 | 直接归档 + Toast |
| 有未完成的任务 | 弹 Dialog「归档计划？」→ 告知未完成任务数 → 确认后归档 |

归档后的结果：
- 从「进行中」Tab 移至「已归档」Tab。
- 其任务从今日页和日历中隐藏（D-09）。
- 可在日记回顾和历史中继续查看。

### 5.2 删除

| 条件 | 行为 |
| --- | --- |
| 仅当计划已被归档且无子任务 | 确认删除 → 永久删除 |
| 被归档但有子任务 | Dialog「永久删除计划及 N 个任务？」 |
| 未被归档的计划 | 不可直接删除；必须先归档 |

> **设计决策 D-37：** 第一版不设「清空计划」（批量删除其中任务）的功能——要清理内容必须先归档或直接删除整个计划。

## 6. 变更影响面

计划日期变更或重新排序时：

| 变更类型 | 受影响页面 |
| --- | --- |
| 修改起止日期 | 今日（健康度变化）、计划板卡片（进度重算） |
| 归档/恢复 | 任务分布在今日/日历的变化 |
| 删除 | 关联任务一并删除（级联） |

刷新通过 `PlanTreeChanged` 事件驱动。

## 7. 验收标准

| 编号 | 验收标准 |

| AC-PLAN-07 | 名称为空或超过 100 字符时无法提交（inline error）。 |
| AC-PLAN-08 | 开始日期 > 结束日期时 Date range inline error。 |
| AC-PLAN-09 | 有未完成的任务时归档需二次确认；完成后 Toast。 |
| AC-PLAN-10 | 已归档计划不可再编辑（控件禁用）；只能恢复或删除。 |
| AC-PLAN-11 | 删除计划后所有关联任务也被删除并出现在今日已删除列表中。 |
