## 1. 目的与范围

定义计划详情页中的阶段（Stage）管理功能：阶段的创建、重命名、删除、展开/折叠，以及任务在阶段间的归属关系。确保用户能够将大型目标拆解为可管理的路线图节点。

**范围内**: 阶段 CRUD、展开折叠、进度计算、空态提示。
**范围外**: 任务拖拽排序（PLAN-04）、跨计划操作（PLAN-04）。

### 3.1 阶段卡片结构

| 区域 | 内容 |
| --- | --- |
| 图标 | `📂` 文件夹图标（SVG 版本） |
| 名称 | 可编辑；点击变输入框 |
| 任务数 | 右下角小字「N 个任务」 |
| 进度条 | 阶段内所有任务的完成率（叶子节点计算） |
| 展开/折叠箭头 | 左侧 chevron icon (`▶` / `▼`) |

### 3.2 展开与折叠

- 默认全部折叠（只显示阶段头和进度条）。
- 点击 chevron 展开/折叠阶段内容。
- 展开后显示阶段内的所有任务树（PLAN-04）。
- 折叠时不隐藏进度条——始终可见。

## 4. 阶段操作

### 4.1 创建阶段

在计划详情页底部或阶段列表末尾的「+ 添加阶段」按钮 → 行内展开一个输入框：

```text
┌───────────────────────────────────┐
│ + 新建阶段 [______________]      │ ← 输入框, placeholder "阶段名称"
└───────────────────────────────────┘
```

- 名称必填，最大 50 字符。
- Enter 确认创建；Esc 取消。
- 创建后立即展开新阶段并聚焦到第一个任务输入框。

### 4.2 重命名阶段

点击阶段名称 → 变为输入框 → 失焦确认保存。

### 4.3 删除阶段

从阶段卡片右上角「⋮」菜单 → 「删除」。

| 条件 | 行为 |
| --- | --- |
| 阶段内有 N > 0 个任务 | Dialog「删除阶段？阶段内 N 个任务将移到计划根。」 |
| 阶段为空 | 直接删除 + Toast |

> **设计决策 D-38：** 删除阶段时默认将任务移到计划根（非级联删除），保护已有工作内容不被误删。

## 5. 进度计算

阶段进度由其下所有**叶子任务**（无子任务的任务）的状态决定：

```
stage_progress = (completed_leaf_count / total_leaf_count) × 100
```

如果阶段内无任务 → 进度 0%（不显示进度条或显示灰色空条）。

## 6. 折叠阈值

当阶段数量 ≤ 3 时默认全部展开；超过 3 个时默认全部折叠。

> **已确认（2026-10-26）Q-PLAN-05：** 阶段折叠阈值是否可配置？→ **当前默认处理：** 硬编码为 3 个（少于等于全展开，超过全折叠）。不设配置项以简化界面。

> **已确认（2026-10-26）Q-PLAN-06：** 阶段是否支持拖拽排序？→ **当前默认处理：** 不支持拖拽排序，只允许通过上移/下移按钮调整顺序。v2 再评估。

> **已确认（2026-10-26）Q-PLAN-07：** 阶段是否需要扩展字段（如颜色标签、描述）？→ **当前默认处理：** 不需要——阶段只是分组容器，额外元数据留在任务级别即可。
