## 1. 目的与范围

定义用户在日历中的日期级别操作行为：点击日期的交互、拖拽改日期（排除）、多任务选择、相邻月切换、日期选择器规格，以及日期冲突的检测与提示。确保日期操作的一致性和安全性。

**范围内**: 日面板、日期修改、冲突检测、日期选择器、hover 切换。
**范围外**: 周/月视图导航（CAL-01）、依赖管理（PLAN-05）。

## 3. 日面板（Day Panel）

### 3.1 打开方式

在月视图或周视图中点击任一日格时，从右侧弹出日面板（宽度 400px，与 TODAY-03 相同规格）。

### 3.2 面板内容

```text
┌─────────────────────────────┐
│ 返回 ←        × 关闭       │
├─────────────────────────────┤
│ 2026年10月23日 周四         │
│                             │
│ ─── 到期 ───                │
│ • [ ] 完成季度报告          │
│ • [ ] 提交设计稿            │
│                             │
│ ─── 开始 ───                │
│ • [x] 团队周会              │
│                             │
│ ─── 未安排 ───              │
│ （无）                       │
│                             │
│ [+ 新建任务]                 │  ← 按钮，以该日为开始日期创建
└─────────────────────────────┘
```

- 按「到期」→「开始」→「未安排」分组显示。
- 已完成的任务不在此面板中列出（遵循 D-09）。
- 「新建任务」按钮打开一个简化对话框：标题 + 日期（默认为该日），快速创建后回到日历视图。

### 3.3 关闭

Esc / 右上角 × / 再次点击其他日期格子（替换为新的日面板）。

## 4. 日期修改

### 4.1 修改入口

在日面板中点击任务行的日期标签，或使用任务详情面板中的日期修改入口（TODAY-03 §4.2）。

### 4.2 日期选择器规格

| 项 | 值 |
| --- | --- |
| 格式 | YYYY-MM-DD |
| 输入方式 | 手动文本输入 或 点选日历控件 |
| 范围限制 | 1900-01-01 到 9999-12-31 |
| 快捷按钮 | 「今天」「明天」「本周」 |

> **已确认（2026-10-26）Q-CAL-05：** 是否支持 Alt+拖拽日期格来修改任务的开始日期？→ **当前默认处理：** 不支持（v1 仅通过详情面板修改），降低实现复杂度和误操作概率。

> **已确认（2026-10-26）Q-CAL-06：** 是否支持多选多个任务后批量拖拽改日期？→ **当前默认处理：** 不支持（v1 单任务修改），后续版本再评估。

### 4.3 冲突检测

修改日期后若产生以下情况：
1. `start_date > due_date` → inline error，阻止保存。
2. 任务移至计划范围之外 → Toast 警告「任务日期超出计划范围」。
3. 前置依赖未满足 → 行内 `⛓` 标记 + tooltip。

所有冲突均以非阻塞方式呈现（D-17），用户可以确认后继续。

## 5. 相邻月操作

### 5.1 hover 切换

当鼠标悬停在靠近边缘的日期格时：

| 行为 | 说明 |
| --- | --- |
| 标准行为 | 高亮当前格，不做页面跳转 |
| 长按 hover（≥500ms） | 自动滚动到相邻月份的对应区域 |

> **已确认（2026-10-26）Q-CAL-07：** 鼠标经过相邻月空白格时是否自动切换月份？→ **当前默认处理：** 不自动切换，避免频繁闪动；需用户主动点击目标月。

### 5.2 拖入相邻月

第一版不支持将任务从一个月的日期拖到另一个月；如需跨月调整，用户先切换到目标月再操作。

## 6. 日期选择器的补充约定

日期选择器不提供年份/月份的下拉面板（如常见的年份滚轮选择器）。用户只能通过以下方式修改年月：

| 方式 | 操作 |
| --- | --- |
| ‹ › 按钮 | 逐月翻页 |
| 手动输入 | 直接键入 YYYY-MM-DD |
| 「今年/本月」按钮 | 快捷跳到当前年份/月份 |

> **已确认（2026-10-26）Q-CAL-08：** 日期选择器是否需要独立的年份/月份选择面板？→ **当前默认处理：** 不需要，仅提供 ‹› 翻页按钮 + 手动输入 YYYY-MM-DD。减少界面复杂度。

| 编号 | 验收标准 |
