## 1. 目的与范围

定义用户在日历中的日期级别操作行为：点击日期的交互、拖拽改日期（排除）、多任务选择、相邻月切换、日期选择器规格，以及日期冲突的检测与提示。确保日期操作的一致性和安全性。

**范围内**: 日面板、复用任务详情日期修改、冲突检测、相邻月导航。
**范围外**: 周/月视图导航（CAL-01）、依赖管理（PLAN-05）。

## 3. 日面板（Day Panel）

### 3.1 打开方式

在月视图或周视图中点击可选日格时，打开宽度 320px 的日面板：窗口宽度 ≥1280px 时并排，较窄时为覆盖抽屉。任务详情另复用 TODAY-03 的 400px 共享抽屉。

### 3.2 面板内容

```text
┌─────────────────────────────┐
│ 返回 ←        × 关闭       │
├─────────────────────────────┤
│ 2026年10月23日 周四         │
│                             │
│ ─── 到期 ───                │
│ • [ ] 完成季度报告          │
│ • [ ] 提交设计稿            │
│                             │
│ ─── 开始 ───                │
│ • [x] 团队周会              │
│                             │
│ ─── 进行中 ───              │
│ ─── 已完成 ───              │
│                             │
│ [+ 新建任务]                 │  ← 按钮，以该日为开始日期创建
└─────────────────────────────┘
```

- 按「到期」→「开始」→「进行中」→「已完成」分组显示，分组条件、去重及排序遵循 ARCH-03 §8.3 和 §9；归档计划的任务不显示（D-09）。无日期的未安排任务不属于具体日期，不显示在日面板。
- 「新建任务」按钮打开简化对话框：标题 + 开始日期（默认为该日），到期日期留空；快速创建后回到日历视图。

### 3.3 关闭

Esc / 右上角 × / 再次点击其他日期格子（替换为新的日面板）。

## 4. 日期修改

### 4.1 修改入口

点击日面板中的任务行，打开全局共享的任务详情面板，通过其日期修改入口操作（TODAY-03 §4.2）。

### 4.2 日期选择器规格

| 项 | 值 |
| --- | --- |
| 格式 | YYYY-MM-DD HH:MM，24 小时制，精确到分钟 |
| 输入方式 | 复用 TODAY-03 的日历和时分选择组件，不要求手动输入 |
| 范围限制 | 1900-01-01 到 9999-12-31 |
| 保存 | 日期与时间组合确认后保存；取消不修改原值 |

> **已确认（2026-10-26）Q-CAL-05：** 是否支持 Alt+拖拽日期格来修改任务的开始日期？→ **当前默认处理：** 不支持（v1 仅通过详情面板修改），降低实现复杂度和误操作概率。

> **已确认（2026-10-26）Q-CAL-06：** 是否支持多选多个任务后批量拖拽改日期？→ **当前默认处理：** 不支持（v1 单任务修改），后续版本再评估。

### 4.3 冲突检测

修改日期后若产生以下情况：
1. 开始晚于到期（含同日双方均有时间时的时分比较）→ inline error，阻止保存。
2. 任务移至计划范围之外 → Toast 警告「任务日期超出计划范围」。
3. 前置依赖未满足 → 行内 `⛓` 标记 + tooltip。

日期范围不变量违反时阻止保存；计划范围和依赖冲突只提示、不阻止（D-17）。

## 5. 相邻月操作

### 5.1 hover 切换

当鼠标悬停在靠近边缘的日期格时：

| 行为 | 说明 |
| --- | --- |
| 标准行为 | 高亮当前格，不做页面跳转 |
| 持续悬停 | 不切换月份 |

> **已确认 Q-CAL-07：** 相邻月灰色日期不可选，悬停不切换；通过导航按钮切换月份。

### 5.2 拖入相邻月

第一版不支持将任务从一个月的日期拖到另一个月；如需跨月调整，用户先切换到目标月再操作。

---

## 6. 日期选择器的补充约定

日历中的任务日期编辑复用 TODAY-03 §4.2 的共享日期时间选择器，不另行定义一套手动输入或年月面板规则。

| 编号 | 验收标准 |

| AC-CAL-07 | 点击可选日格打开日面板，正确显示该日的到期/开始/进行中/已完成分组任务。 |

| AC-CAL-11 | Esc 关闭日面板后日历视图恢复正常。 |
| AC-CAL-12 | 相邻月 hover 不触发自动切换。 |
