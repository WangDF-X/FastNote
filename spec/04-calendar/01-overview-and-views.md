## 1. 目的与范围

定义日历页面的两种视图模式（月视图 + 周视图）及其切换、导航、日期选择的行为，以及日期面板中任务的聚合展示。确保用户以时间维度快速浏览和定位任务安排。

**范围内**: 月/周视图切换、月份/周导航、选中日、日期面板内容、周起始日配置。
**范围外**: 拖拽改日期（CAL-02）、事件创建弹窗（CAL-02）。

## 3. 视图模式

### 3.1 月视图（默认）

```text
┌─────────────────────────────────────┐
│  ◀ 2026年10月 ▶     [月][周]      │  ← 头部
├─────────────────────────────────────┤
│ 一 二 三 四 五 六 日                │  ← 星期头
│                                     │
│ ┌───┬───┬───┬───┬───┬───┬───┐     │
│ │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │ 7 │ ... │  ← 月份网格
│ │   │   │✓2 │✓1│   │   │   │     │
│ ├───┼───┼───┼───┼───┼───┼───┤     │
│ │ 8 │ 9 │...                                           │
│ └───┴───┴───┴───┴───┴───┴───┘     │
│                                     │
└─────────────────────────────────────┘
```

- 每行 7 列；不足补前/后月的空白格（灰显日期数字，不可选）。
- 当月今天用 `accent` 底色高亮。
- 每个日期格底部显示弱提示 `✓N`（已完成数，N ≤ 9；超过显示 `✓9+`）。

### 3.2 周视图

```text
┌─────────────────────────────────────┐
│ ◀ 2026年10月19日 - 25日 ▶   [月][周]|
├─────────────────────────────────────┤
│ ┌─────┬─────┬─────┬─────┬─────┬───┐ │
│ │ 周一 │ 周二 │ 周三 │ 周四 │ 周五 │ 六 │ │
│ │ 10/19│10/20│10/21│10/22│10/23│10/24│ │
│ │ ✓2  │     │ ✓1  │     │     │    │ │
│ ├─────┼─────┼─────┼─────┼─────┼───┤ │
│ │ 日   │                                    │ │
│ │ 10/25│                                    │ │
│ │ ✓3  │                                    │ │
│ └─────┴─────┴─────┴─────┴─────┴───┴───┘ │
└─────────────────────────────────────┘
```

- 水平排列，从左到右 7 天。
- 左侧固定宽度，右侧自适应填充；总宽度不超过内容区上限。
- 当前天同样 `accent` 底色。

### 3.3 视图切换

- 头部右上角有两个按钮 `[月] [周]`，当前激活的加粗显示为 accent 色。
- 切换时保留上次选中的日期锚点（如月 → 周时，选中的日成为所在周的锚点）。
- 无转场动画，即时切换。

## 4. 导航

### 4.1 月视图导航

| 操作 | 效果 |
| --- | --- |
| `◀` / `▶` 按钮 | 上/下一个月 |
| `PageUp` / `PageDown` | 上/下一个月 |
| `T` 键 | 回到今天 |
| 点击某日期格 | 选中该日期（右侧出现日面板或在宽屏下下方展开详情） |

### 4.2 周视图导航

| 操作 | 效果 |
| --- | --- |
| `◀` / `▶` 按钮 | 上/下周 |
| `PageUp` / `PageDown` | 上/下周 |
| `←` / `→` | 左/右移动一天 |
| `T` 键 | 本周到今天 |

| 元素 | 值 |
| --- | --- |
| 标题 | `日历` |

## 6. 平台差异

### 6.1 触摸与手势

| 平台 | 支持情况 |
| --- | --- |
| Windows（触控屏） | 不支持触摸滑动翻页 |
| macOS | 不支持 |
| Linux | 不支持 |

仅通过按钮和键盘快捷键导航。

> **已确认（2026-10-26）Q-CAL-01：** 是否支持触控板滑动切换月份？→ **当前默认处理：** 不实现（v1 仅按钮 + 键盘），避免触控板误触发影响其他页面。

### 6.2 周起始日

周起始日由设置项 `general.week_starts_on` 控制：

| 值 | 说明 |
| --- | --- |
| `Monday`（默认） | 周一到周日 |
| `Sunday` | 周日到周六 |

在设置页可修改，修改后立即刷新日历所有视图。

## 7. 日期聚合显示

每个日期格内最多显示三条任务标题（超出行溢出 `…`）。点击该格子打开对应日期的详情页（日面板或侧边抽屉）。

已完成任务只显示弱计数 `✓N`，不在格子中列出具体标题。

> **已确认（2026-10-26）Q-CAL-02：** 月视图日期格中是否显示已完成的任务条目？→ **当前默认处理：** 不显示具体任务，只显示完成的计数 `✓N`（弱提示）。

> **已确认（2026-10-26）Q-CAL-03：** 是否需要显示农历/节假日标记？→ **当前默认处理：** 不实现（D-06 无网络，且第一版不需要农历支持）。
