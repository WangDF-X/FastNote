## 1. 目的与范围

定义 FastNote 的界面布局、视觉令牌、组件规范与交互状态，保证五个模块在同一套语言下呈现，并为 Slint 实现提供可落地的参数。

**范围内**：窗口与栅格、颜色/字体/间距/圆角/阴影/动效令牌、基础组件、状态与空态、可访问性、主题与密度。
**范围外**：逐页面线框与业务交互（各模块文档）、品牌 Logo 设计、高保真视觉稿。

---

## 2. 设计原则

1. **安静**：默认低对比、低饱和；强调色只用于可操作与当前状态，不用大面积色块。
2. **一眼可读**：标题、日期、状态、优先级形成稳定的阅读顺序；不靠颜色单独传达信息（同时有文字/图标）。
3. **密度可控**：默认舒适，提供紧凑模式；信息优先于留白，但不拥挤。
4. **不打断**：提示优先于弹窗；只有破坏性/不可逆操作使用模态确认。
5. **一致**：同一语义使用同一颜色、图标与文案；跨模块复用组件。
6. **轻**：无持续动画、无模糊背景、无重阴影；窗口隐藏时停止重绘（ARCH-01 §5.3）。

### 4.5 间距、圆角、阴影、动效

| 令牌 | 值 |
| --- | --- |
| 间距阶 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 |
| 页面内边距 | 24（舒适）/ 20（紧凑） |
| 组件内边距 | 8 / 12 / 16 |
| 圆角 | 6（输入/按钮）、10（卡片）、14（对话框）、999（胶囊/悬浮球） |
| 阴影 sm | `0 1px 2px rgba(20,24,32,.08)` |
| 阴影 md | `0 8px 24px rgba(20,24,32,.12)` |
| 阴影 lg | `0 16px 48px rgba(20,24,32,.18)` |
| 动效 快 | 120ms `cubic-bezier(.2,0,0,1)`（hover、勾选） |
| 动效 中 | 180ms（详情面板、展开折叠） |
| 动效 慢 | 240ms（对话框） |

**动效约束**

- 禁止无限循环动画（呼吸灯、旋转 loading 持续展示）；加载超过 200ms 才显示静态骨架或不确定进度条。
- 进度条数值变化使用 180ms 过渡；不做数字滚动动画。
- 支持「减少动态效果」时（平台可检测则跟随），将动效时长设为 0。

## 5. 基础组件

> 所有组件必须定义 default / hover / active / focus / disabled / error 状态；下表中的尺寸为舒适模式，紧凑模式统一减 4px 高度、左右内边距减 2px。

### 5.1 按钮

| 类型 | 高度 | 背景 | 文字 | 用途 |
| --- | --- | --- | --- | --- |
| Primary | 32 | `accent` | 白 | 页面主操作（新建、保存确认） |
| Secondary | 32 | `bg.surface` + `border.default` | `text.primary` | 次要操作（取消、编辑） |
| Ghost | 32 | 透明 | `text.secondary` | 行内操作、工具栏 |
| Danger | 32 | `danger` | 白 | 确认删除 |
| Text Link | 20 | 透明 | `accent` | 跳转、查看详情 |

- 圆角 6；图标 + 文字间距 6；只有图标时使用 32×32 IconButton，必须有 tooltip/aria 文案。
- 禁用：透明度 45%，不改变布局；hover 不响应。
- 主操作每屏最多 1 个；危险按钮不使用主色。

### 5.2 输入

- 单行高度 36；多行最小 80，可随内容增长（最高 240 后内部滚动）。
- 边框 1px `border.default`；聚焦时 `accent` 边框 + 2px 外发光（focus ring）。
- Placeholder 用 `text.tertiary`，不与正文同色。
- 错误态：`danger` 边框 + 下方 12px 错误文案 + 图标；输入内容不清空。
- 字符计数：接近上限（≥90%）时在右下角显示，超限阻止输入并提示。
- 中文 IME 组合输入期间不触发快捷键/提交（见 SHELL-02）。

### 5.3 任务勾选

- 18×18 圆形；未完成空心 `border.strong`，hover 显示浅色对勾预览；完成填充 `success` + 白色勾。
- 点击区域 32×32（含行内边距）。
- 状态为进行中/等待中时，勾选控件外圈显示对应语义色细环。

### 5.4 标签与徽标

| 组件 | 高度 | 样式 | 示例 |
| --- | --- | --- | --- |
| 状态徽标 | 20 | `bg.subtle` + 语义色文字 | 进行中、等待 3 天 |
| 优先级标记 | 16 | 色点/短横 + tooltip | 高 |
| 计划徽标 | 20 | `bg.subtle` + `text.secondary` | 计划 A |
| 阶段徽标 | 20 | 透明 + `border.default` | 需求整理 |
| 计数徽标 | 18 | 胶囊，`bg.subtle` | 3 |
| 逾期文字 | — | `danger` 12px | 逾期 2 天 |

- 计划徽标最多 1 个；超出用 tooltip 展示完整层级（计划 · 阶段）。
- 徽标不换行，超长省略号，最大宽度 160。

### 5.5 进度

- 轨道高 6（阶段）/ 8（计划头部），圆角 999，轨道 `bg.subtle`，填充 `accent`；100% 时 `success`。
- 右侧文字 `62%` + `12/19`（可省略分子分母，视空间）。
- 无任务：显示「暂无任务」，轨道为空，不显示 0%。
- 阶段头部进度条宽度固定 120；计划头部自适应（最大 320）。

### 5.6 列表行

```text
[勾选 32] [标题 自适应，省略] [优先级] [日期] [计划/阶段] [依赖图标] [菜单 28]
```

- 行高 40（紧凑 32）；hover `bg.hover`；选中 `bg.selected`；焦点 2px `accent` 内描边。
- 标题单行省略；双击或 Enter 打开详情（单击行也打开，勾选区域除外）。
- 已完成标题加删除线，颜色 `text.tertiary`。
- 行内操作默认隐藏，hover/键盘聚焦时显示，避免视觉噪音。
- 分组头（Section Header）：高 36，粘性吸顶，左侧折叠箭头，右侧计数；计数为 0 时整组隐藏（今日页除外，见 TODAY）。

### 5.7 日期显示

| 场景 | 格式 | 示例 |
| --- | --- | --- |
| 今天 | 今天 | 今天 |
| 明天 | 明天 | 明天 |
| 过去 7 天内 | 周X | 周二 |
| 今年内 | MM-DD | 10-28 |
| 跨年 | YYYY-MM-DD | 2027-01-03 |
| 逾期 | 逾期 N 天 | 逾期 2 天 |
| 区间 | `MM-DD → MM-DD` | 10-01 → 10-15 |

- 数字使用 tabular-nums 对齐；不显示「剩余 0 天」。

### 5.8 下拉、日期选择、菜单

- 下拉：触发器同输入框；面板 8px 圆角 + md 阴影，最大高 280，内部滚动；选中项左侧勾。
- 日期选择：280 宽月历 + 顶部「今天 / 明天 / 清除」快捷；支持键盘方向键；选择后立即生效。
- 上下文菜单：220 宽，32 行高，图标 16 + 文字；危险项红色；支持键盘上下/Enter/Esc。

### 5.9 对话框、抽屉、Toast

| 组件 | 规范 |
| --- | --- |
| 对话框 | 最大宽 480，圆角 14，padding 24；标题 Section；正文 14；按钮右对齐（取消在左）。遮罩点击关闭仅对非破坏性弹窗；破坏性弹窗必须显式选择。 |
| 抽屉（任务详情） | 右侧 400，全高，`bg.surface`，左侧 1px 边框 + md 阴影；非模态，无遮罩；Esc 关闭；打开时不抢列表焦点之外的输入焦点（新建任务除外）。 |
| Toast | 底部居中，距底 24；宽 320–420；`bg.surface` + border + md 阴影；图标 + 文案 + 可选 1 个操作；3s 自动消失（错误 6s）；最多同时 3 条，超出排队。 |
| 确认框 | 标题为动作（「删除任务？」），正文说明影响（数量、不可恢复），主按钮使用动作动词（「删除」），不用「确定」。 |

### 5.10 空态

```text
        [线性图标 40，text.tertiary]
        标题 15/22（如「今天还没有任务」）
        说明 13/20 text.secondary（最多两行）
        [主操作按钮]（可选）
```

- 空态不展示插画照片；使用单色线性图标。
- 页面级空态与分组级空态区分：分组为空直接隐藏，页面为空才展示空态。

### 5.11 加载与保存状态

- < 200ms：不显示 loading。
- 200ms–2s：3 行骨架（`bg.subtle` 圆角块，无闪烁动画）。
- > 2s：进度文案（「正在准备备份…」）。
- 文本自动保存：页面头部右侧显示「已保存 14:32」；保存中 > 300ms 显示「保存中…」；失败显示红色「保存失败，重试」。
- 任务修改为即时保存，不显示逐条「已保存」，仅在失败时提示。

## 6. 页面模式

### 6.1 列表 + 详情

- 今日任务、计划板任务树、日历日面板：点击行打开右侧详情抽屉。
- 抽屉打开不改变页面滚动位置；关闭后焦点返回原行。

### 6.2 主从布局

- 小记：左列表 300 + 右编辑器自适应；列表选中项高亮。
- 日记：左月历/条目导航 260 + 右编辑器；窄屏（<1180）时左栏折叠为顶部日期条。

### 6.3 计划路线图

```text
● 01  需求整理                 10-01 → 10-15    ▓▓▓▓▓▓░░░░  62%  12/19
│     ├ ☑ 竞品分析                              10-10
│     ├ ☐ 需求文档        ⛓ 依赖：竞品分析      10-15   [高]
│     └ ☐ 用户访谈                              10-12
● 02  界面设计                 10-16 → 10-31    ░░░░░░░░░░   0%   0/14
│     └ …
● 03  功能开发                 11-01 → 11-30    ▓▓▓▓░░░░░░  41%   9/22
```

- 左侧竖线 + 节点圆点表示阶段顺序；阶段行高 56；任务行 36；缩进 20/层，最多 8 层后保持缩进并显示 `Lv.N` 徽标。
- 阶段可折叠；折叠状态仅前端记忆（会话内），不落库。
- 添加阶段/任务的入口在分组末尾，hover 显示，键盘可聚焦。

### 6.4 日历

- 月视图：7 列等宽，格高自适应（最小 96），今日格 `accent.subtle` 底 + 日期 `accent`；非本月日期 `text.tertiary`。
- 任务摘要最多 2 条 + `+N`；逾期红点；完成弱化。
- 选中日期格 2px `accent` 边框；右栏日面板标题显示「10月23日 周四」。

## 7. 主题与密度

- 主题三态：跟随系统 / 浅色 / 深色；切换后 120ms 内全局生效，不重启、不闪烁。
- 系统主题变化实时跟随（监听平台事件；失败则下次启动生效）。
- Slint 实现建议：全局 `Palette` 单例，所有颜色绑定到 `Palette.xxx`；Rust 在主题变化时整体替换调色板。
- 密度：舒适 / 紧凑；仅影响行高、内边距、字号（Body 13），不影响窗口尺寸与布局结构。
- 不使用纯黑（#000）与纯白大面积；深色模式避免纯黑底 + 纯白字造成眩光。

---

## 8. 可访问性

1. **键盘**：所有功能可仅用键盘完成；Tab 顺序按视觉顺序；焦点环 2px `accent` + 2px 偏移，永不移除。
2. **对比度**：正文与背景 ≥ 7:1，辅助文字 ≥ 4.5:1；颜色不作为唯一语义。
3. **命中区域**：最小 28×28；主要操作 ≥ 32×32；行整行可点。
4. **文本缩放**：跟随系统 DPI；不在应用内提供小于 11px 的文字。
5. **动效**：尊重系统「减少动态效果」；无闪烁、无自动播放动画。
6. **朗读**：Slint 的无障碍树能力有限；按钮/图标提供可读文本与 tooltip；关键状态变更通过 Toast 文字表达。
7. **IME**：输入框支持中文组合输入；组合期间不触发 Enter/Esc/单键快捷键。

## 9. 文案规范

- 动词开头、具体、可执行：「添加任务」「归档计划」「从备份恢复」。
- 不使用「确定/取消」作为主按钮文案（对话框用具体动词）；「取消」可保留。
- 错误说明「发生了什么 + 怎么办」，不暴露代码/堆栈：
  - 好：「开始日期不能晚于完成日期。」
  - 差：「Validation error: E_DATE_RANGE」。
- 不使用感叹号、不责备用户（避免「你输入错了」）。
- 数量使用阿拉伯数字；时间使用 24 小时制（14:32）。
- 空态文案给下一步：「今天还没有任务。按 Ctrl+N 或在下方输入框快速添加。」
