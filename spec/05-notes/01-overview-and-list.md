## 1. 目的与范围

定义小记页面的核心展示：左侧 300px 分组列表与右侧自适应正文编辑器、排序方式、分组（按本地更新时间日期）、快速删除与恢复机制。确保用户能够快速浏览和管理临时记录内容。

**范围内**: 列表渲染、排序与分页、清理操作、恢复提示。
**范围外**: 快速捕获窗口（NOTE-02）、小记转任务（NOTE-02）、系统通知提醒（REM-01）。

**资源生命周期（D-RES-01，2026-11-04 已确认）：** 列表分页/摘要仅进入页面时查询，完整正文只为当前编辑或必要草稿读取，不缓存全部历史小记。离开/隐藏优先回收已保存正文和大型列表模型，低成本缓存最多随主窗保留 120 秒；选中 ID、滚动/分页等轻量会话保留，旧查询不能重建已卸载页。独立快速捕获不预建主窗或主列表，保存后隐藏列表只失效；主窗回收不关闭正在编辑的捕获窗。草稿/提醒及容量规则见 [ARCH-01 §5](../00-architecture/01-tech-and-runtime.md) / [SHELL-01 §5.5](../01-app-shell/01-overview.md)，本次为要求对齐，未执行功能实现或资源验收。

## 3. 页面布局

```text
小记
├── 共 N 条                         ← 内容内统计，无公共模块标题条
├── [今日]                        ← 分组头（可按日期折叠）
│   • 标题行 1           10:23    ← 摘要 + 更新时间
│   • 标题行 2           09:15
│                                 
├── [昨天]
│   • 另一条笔记         18:45
│   
├── [10月18日]
│   ···
└── [+ 快速添加]                  ← 底部固定按钮
```

- 每个分组最多 20 条；超出后显示「查看更多」。
- 每条笔记显示：首个非空行最多 80 字符的派生标题、最多两行/120 字符的预览及本地更新时间（HH:mm）。不设独立标题字段，摘要规则统一引用 ARCH-03 §3.4/11.4。
- 点击条目打开编辑模式。
- D-SHELL-02 将今日日期/周几放到侧栏，移除公共标题条；内容内数量、分组与编辑保存状态保留。

## 4. 排序规则

| 排序依据 | 说明 |
| --- | --- |
| `updated_at DESC`（默认） | 最近修改的在最上面 |
| `created_at DESC` | 新创建的在最上面 |

设置中不提供排序切换入口（第一版固定为 updated_at DESC）。

> **已确认（2026-10-26）Q-NOTE-01：** 是否允许用户手动排序或固定置顶某些小记？→ **当前默认处理：** 不支持，仅按 updated_at 降序排列。v2 再评估 Pin/Manual Sort。

## 6. 清理操作

### 6.1 单次删除

点击条目右侧「⋮」菜单 → 「删除」 → 弹确认 Dialog → 永久删除。

### 6.2 清除全部

页面底部「清理全部」按钮 → 弹确认 Dialog「删除所有 N 条小记？」 → 确认后全部删除。

### 6.3 自动回收提示

如果用户在清理操作中误删了有重要内容的笔记，第一版不提供回收站。但在删除成功后 Toast 中增加一个可选操作「撤销」（2s 内有效），撤销后将该批次恢复。

> **已确认（2026-10-26）Q-NOTE-02：** 用户一次性清空全部小记后，是否提供全局级别的恢复？→ **当前默认处理：** 不实现全局恢复（无回收站）；仅在一次操作的撤销窗口内可恢复同批次删除的内容。Toast 中显示恢复选项并限制在 2s 内。

## 7. 保存策略

- 每次创建/修改小记后立即写入 SQLite。
- 文本编辑 500ms 防抖自动保存。
- 保存失败时 inline error + 页面级 Banner。
- 正文去空白后必须非空且不超过 20,000 字符；原始换行及首尾空白保留。清空已存在小记不隐式删除，保留草稿并提示「请输入内容」，删除必须走确认流程。
- 失焦、切换小记、离页及隐藏/退出先冲刷待保存正文；失败保留当前草稿，不切换或卸载。保存中继续输入时，旧回包不得覆盖新草稿。

> **已确认（2026-11-09）D-NOTE-01 / Q-NOTE-06/07：** 用户要求在当前 `feature/mark` 开发完整小记闭环，选择统一领域模型（仅正文、20,000 字符、80 字派生标题和两行/120 字预览）；转任务手填标题、日期默认留空，可显式设置日期。范围为列表/编辑、删除撤销、独立快速捕获、转换与解绑，不包含系统提醒。删除撤销仅恢复最新操作的同批次，成功后 2 秒内有效；批次正文不进入 UI 或 Rust 历史列表缓存，过期即回收。规格进入 In Progress，自动检查不替代用户 UI 验收，不自动提交。

## 8. 验收标准

| 编号 | 验收标准 |
| --- | --- |
| AC-NOTE-01 | 小记页按 updated_at DESC 排序，分组按日期；每组最多 20 条。 |
| AC-NOTE-02 | 点击条目进入编辑，修改后失焦立即保存成功。 |
| AC-NOTE-03 | 空态时正确显示空态文案和「写第一条」按钮。 |
| AC-NOTE-04 | 删除单条需确认；删除全部需二次确认。 |
| AC-NOTE-10 | 单条/全部删除成功后 2 秒内可撤销同批次；超时不能恢复，连续删除只允许撤销最新批次，转换关联及已有提醒数据保持一致。 |
| AC-NOTE-11 | 正文超过 20,000 字符或为空时不能保存；失败/切换/隐藏不丢失草稿，旧保存与查询回包不覆盖新草稿或复活已卸载页。 |
| AC-NOTE-12 | 未进入或隐藏小记页不查询历史列表；仅按需读取当前正文，离页回收已保存正文和列表，快速捕获不预建主窗。 |
