## 3. 快速捕获窗口

### 3.1 窗口属性

| 项 | 值 |
| --- | --- |
| 尺寸 | 默认 480 × 320 逻辑像素；最小 360 × 240 |
| 形态 | 置顶不透明窗口；非模态（不影响其他页面操作） |
| 标题栏 | 原生操作系统标题栏，标题 `FastNote - 快速捕获` |
| 焦点 | 打开时聚焦到输入框；ESC 关闭窗口（如果有内容则弹出确认 Dialog） |
| 位置 | 屏幕中央偏上；每次打开时居中计算 |

> **已确认（2026-10-26）Q-NOTE-03：** Wayland 下若不支持独立置顶窗口，是否回退到主窗口内的浮动面板？→ **当前默认处理：** 支持回退——在 Wayland 环境下于主窗口内以浮层面板形式提供快速捕获功能。

### 3.2 布局

```text
┌───────────────────────────────────┐
│ FastNote - 快速捕获       ×      │ ← 原生标题栏
├───────────────────────────────────┤
│ 标题 [_________________________]  │ ← 可选，placeholder "标题（可选）"
│                                   │
│ ┌───────────────────────────────┐ │
│ │                               │ │
│ │          正文区...              │ │ ← textarea, 自动聚焦
│ │                               │ │
│ │                               │ │
│ └───────────────────────────────┘ │
│                                   │
│         [保存]   [丢弃]           │ ← 底部按钮区
└───────────────────────────────────┘
```

- 标题行可选；不填时创建的小记 title = NULL。
- 正文区最大长度 2000 字符，超出后截断并 Toast 警告。
- 「保存」按钮或 `Primary+S` / `Ctrl+S` → 保存并关闭。
- 「丢弃」按钮 → 丢弃当前内容并关闭。
- ESC → 有内容时弹 Dialog「保存这条小记？」→ 三选一：保存并关闭 / 丢弃 / 取消；空内容直接关闭。

### 3.3 保存行为

| 动作 | 结果 |
| --- | --- |
| 点击「保存」 | 写入 DB → Toast「已保存」→ 关闭窗口 |
| `Primary+S` | 同点击「保存」 |
| 「丢弃」 | 不写 DB → 关闭窗口 |
| ESC（空内容） | 直接关闭窗口，不弹确认 |

保存成功后：
1. 关闭快速捕获窗口。
2. 主窗口的小记列表通过 `NotesChanged` 事件刷新，新条目出现在最上面。

### 3.4 位置记忆

> **已确认（2026-10-26）Q-NOTE-04：** 快速捕获窗口是否记住上次关闭时的位置？→ **当前默认处理：** 不记忆位置（每次打开都居中显示），避免在多显示器环境下出现"消失的窗口"。

## 4. 小记转任务

### 4.1 触发方式

在小记列表中，点击某条笔记右侧「⋮」菜单 → 「转为任务」。

### 4.2 转换流程

```text
1. 弹出小型对话框：
   ├── 标题输入框（可编辑小记摘要作为标题）
   ├── 开始日期：默认今天
   ├── 到期日期：留空（未安排）
   └── [确认转换] [取消]

2. 确认后：
   a. 创建 Task 实体
   b. 关联 Note 与 Task（note_id → task_id）
   c. 小记列表中该条目显示「已转换 ✓」（灰色标记）
   d. Toast「已创建任务」+ 操作「查看」（打开任务详情）
   e. 今日页刷新（新任务出现在未安排组）
```

### 4.3 标题填充

> **已确认（2026-10-26）Q-NOTE-05：** 转换时是否自动用小记的前 N 个字符填充 title 字段？→ **当前默认处理：** 不自动填充——title 保持为空让用户手动填写；如果用户不填就提交则报错（不能有空标题）。

### 4.4 解除关联

小记转为任务后可以解除关联：
- 在任务详情面板中点击「解绑」或在小记中重新选择「恢复为纯小记」。
- 解除后 Task 保留但不再关联 NoteId；Note 回到普通状态。
