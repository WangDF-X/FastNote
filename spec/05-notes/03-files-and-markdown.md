# NOTE-03 小记文件与 Markdown

## 1. 已确认的产品调整

用户确认，小记页面改为文件夹与文件结构，支持新建空白小记，Markdown 在同一区域切换编辑和预览，不使用左右分栏。本文取代 NOTE-01/02、ARCH-03 中与独立文件名、正文非空、日期分组以及 Markdown 范围冲突的旧规则；其他无冲突规则继续有效。

## 2. 文件与目录

- 小记具有独立、可重命名的文件名，正文为 Markdown 源码；根目录和文件夹内均可新建小记或文件夹。确认文件名后即可持久保存空正文。
- 文件和文件夹均支持新建、重命名、拖拽移动和删除。根目录不计层，文件与文件夹均计入路径层数，最多三层；移动文件夹时其所有后代也必须满足限制，不得移动到自身或后代之中。
- 展开文件夹时，其下级文件夹默认收起；收起文件夹时，其后代文件夹也跟随收起。
- 同一目录下文件和文件夹名称遵循 Windows 文件管理器规则，包括大小写不敏感的重名判断、禁止特殊字符及保留设备名、名称末尾不能是空格或句点。新建、重命名或移动遇到冲突时提示并要求改名，不覆盖原数据。
- 删除非空文件夹需确认并级联删除全部后代；删除撤销仍只保留最新批次、两秒内有效，恢复包含层级和提醒数据。恢复时若名称冲突则自动改名，不覆盖已有内容；事务失败不能部分删除或恢复。
- 现有小记自动迁移至根目录，保留正文、创建及更新时间；初始文件名取原派生标题，重名自动编号。用户表示目前小记没有数据，仍须沿用数据库版本检查和迁移前备份，并保留可能存在的提醒及投递记录。移除小记与任务的关联时保留任务和小记本身，不删除任务。
- 独立快速捕获仍只输入正文，非空保存至根目录，文件名取正文首个非空行，重名自动编号；空白捕获不保存。

### 2.1 目录操作修复（D-NOTE-02，2026-11-09 用户确认）

- 保留可展开的树形目录，不改成当前文件夹内容列表。点击文件夹名称只选中，左侧箭头只展开/收起；选择小记（包括右键选中）时打开右侧编辑，并先保护现有草稿。
- 文件夹右键菜单提供展开/收起、在其中新建小记/文件夹、重命名、删除；小记右键提供编辑、重命名、删除。目录空白处右键在根目录新建。删除仍须明确确认，沿用级联删除和两秒撤销规则。
- 移除目录区的“根目录”“新建文件夹”和每行常驻的重命名/删除按钮；保留顶部“新建小记”。顶部新建：选中文件夹时建在其中，选中文件时建在其父目录，未选中时建在根目录。弹窗打开时固定新建目标，不随之后的选择变化。
- 将目录区“新建位置：”替换为只读路径栏，展示左侧选中项的完整虚拟路径（例如 `小记\工作\想法`）；无选中项时显示 `小记`。重命名、移动、删除及撤销后重新计算，不将 SQLite 内的虚拟目录误作操作系统磁盘路径。
- 返回/前进记录左侧选中位置，上一级选择其父目录；恢复位置时展开必要的祖先并定位到节点。根目录的上一级及不可用的历史按钮禁用；重复选择不重复入栈，新选择清除前进历史，已删除节点从历史移除，历史仅保留有界的轻量标识。
- **目录选择与右侧文件（2026-11-09 用户修订）**：选中文件（包括返回/前进导航到文件）时右侧同步打开该文件；切换前先保存当前草稿，失败保留草稿并阻止切换。选中文件夹或根目录、展开/收起文件夹时右侧保持原文件，不自动打开子文件。此规则取代此前“导航只作用于左侧”的约定。右键菜单仍针对被点击节点。
- 重命名在原文件名处输入，不弹窗；Enter 提交、Esc 取消，输入框获得真实焦点并选中原名称。非法名称、重名或写入失败在原位提示并保留输入，成功才关闭输入框。重命名不改变正文，右侧已打开文件的保存基线必须同步，旧回包不得覆盖草稿。
- 本轮不修改 Markdown 渲染、数据库结构、提醒和跨模块业务范围；目录状态逻辑由自动测试验证，界面和交互由用户手工验收。

## 3. 编辑与预览

- 小记列表可由用户展开或收起为抽屉；新建按钮打开文件名输入弹窗。编辑与预览为相邻的图标按钮，显示选中状态；小记展示创建和最近修改日期。
- 顶部文件名、保存状态和创建/修改时间只在打开小记文件时显示，描述右侧当前文件；文件名突出，已保存为绿色、未保存为红色，保存中和失败有明确状态。目录数量始终显示“共 N 条”，数字使用绿色背景，不随导航按钮悬停改变。路径栏使用浅/深主题适配的蓝灰背景及独立根目录图标，节点以箭头分隔，根目录不显示“小记”文字；仅展示，不支持点击跳转或悬停浮层。目录行更紧凑，新建弹窗打开即聚焦名称输入框。

- 默认编辑 Markdown 源码，通过操作在**同一内容区域**切换为渲染预览，再切换回编辑；不展示并排预览。编辑时每 10 秒自动保存，点击预览也自动保存。保存失败须提示并提供重试，保留当前内容并阻止预览、切换文件及关闭等操作，直到保存成功或用户明确选择丢弃。
- **保存交互（2026-11-09 用户确认）：** 在主窗口点击正文编辑区以外的位置时结束正文输入焦点并立即触发保存，同时保留所点击控件的原有操作；在小记编辑状态按 `Ctrl+S` 立即保存，不移动输入焦点。保存失败保留草稿、显示失败并允许重试，切换文件或离开页面仍受保存保护。此要求不扩展到点击其他应用或桌面，不增加保存按钮。
- 第一版支持标题、粗体、斜体、删除线、无序与有序列表、任务列表、引用、行内代码、围栏代码块和链接；不支持图片和表格。
- 正文上限仍为 20,000 Unicode 字符；空白正文可保存。小记独立于任务，不提供转任务或解绑功能。
- 列表及正文遵循 D-RES-01 的按需读取和卸载规则；尚未保存或保存失败的编辑内容不可静默丢弃。
- 若现有控件不能满足预览要求，可评估其他原生控件或依赖；须说明依赖、资源和性能影响，不引入 WebView。

## 4. 验收标准

1. 空库可新建并重开空白小记；文件名与正文独立，重命名不更改正文。
2. 根目录及不同层级可创建、移动、重命名、删除；重名和超过三层均被阻止，文件夹不能移入自身或后代。
3. 删除非空文件夹先确认；有效期内撤销完整恢复层级、正文、时间和提醒，名称冲突时自动改名；超时或更晚的删除使旧撤销失效。
4. 编辑和预览在同一区域切换，常用格式正确显示；编辑源码、切换和保存后重新打开内容不变，保存失败保留草稿。
5. 旧库迁移后正文、时间与提醒不丢失，任务和小记均保留但不再关联，重名文件获得不同名称；失败时原库可恢复。
6. 预览不能执行 Markdown 内嵌脚本或加载未授权的远程内容；不支持的语法不应损坏源码。
7. 文件夹名称选择与箭头展开分离；右键操作始终作用于被点击文件/文件夹，空白处和文件夹内的新建位置准确。
8. 重命名不弹窗，Enter 保存、Esc 取消；重名/非法名称保留输入并提示，文件正文与目录层级不受影响。
9. 路径栏完整表示左侧选中项，移动/重命名/删除/撤销后没有过期路径；目录区不再显示根目录/新建文件夹按钮或每行常驻编辑/删除按钮。
10. 返回/前进/上一级能恢复或定位左侧节点，按钮禁用状态与历史一致；导航到文件时打开该文件并保护未保存草稿，导航到文件夹或根目录时不改变右侧文件和内容。
11. 正在编辑的小记重命名或其祖先重命名后继续保存无版本冲突；删除节点及后代后历史不指向已删除项，保存失败时切换文件不丢失草稿。
12. 文件信息只描述当前打开的小记；数量保持“共 N 条”，路径栏无悬停浮层，目录行紧凑；新建弹窗打开后可直接输入名称。
13. 编辑小记后点击左侧空白、目录及主窗口其他区域，输入光标失焦且草稿保存；原点击操作仍生效。`Ctrl+S` 触发保存但光标保留；保存失败仍可重试且不丢草稿。
