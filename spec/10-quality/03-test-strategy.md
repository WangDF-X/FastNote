## 1. 目的与范围

定义 FastNote 第一版的测试分层、必测场景、测试数据、性能基准、平台矩阵与发布门禁，确保「统一任务」「跨模块一致」「本地数据安全」三类高风险点被系统性覆盖。

**范围内**：单元/集成/UI/平台/性能/迁移/恢复测试，CI 门禁与发布清单。
**范围外**：具体测试代码、CI 供应商配置、渗透测试、商店审核材料。

## 2. 测试分层

| 层 | 对象 | 工具/方式 | 运行频率 | 门禁 |
| --- | --- | --- | --- | --- |
| L1 领域单元测试 | `fastnote-core` 规则、派生、校验、状态机 | `cargo test`，固定 `Clock`，内存仓储 | 每次提交 | 必须全绿 |
| L2 存储集成测试 | SQLite schema、事务、外键、迁移、查询 | 临时目录真实 SQLite | 每次提交 | 必须全绿 |
| L3 应用集成测试 | Command/Query/Event、事务回滚、并发、刷新 | 测试装配（真实 store + 内存 UI 回调） | 每次提交 | 必须全绿 |
| L4 视图模型测试 | DTO → UI 状态映射、排序/分组展示、空态/错误态 | 纯 Rust 测试，不渲染 | 每次提交 | 必须全绿 |
| L5 UI 冒烟/渲染 | 关键页面渲染、交互回调、焦点 | Slint 测试接口（若可用）/手工 | 每日 + 发布前 | 不阻断合并，阻断发布 |
| L6 平台手工测试 | 入口、托盘、快捷键、自启、IME、DPI、多屏 | 三平台清单 | 每个里程碑 | 阻断发布 |
| L7 性能/资源 | 启动、内存、CPU、查询、滚动 | 脚本 + 参考机 | 每周 + 发布前 | 超阈值阻断发布 |
| L8 数据安全 | 备份恢复、导入导出、崩溃恢复、损坏处理 | 自动化 + 手工 | 发布前 | 阻断发布 |

> **设计决策 D-QA-01：** 核心规则不依赖 UI 测试兜底。L1 必须覆盖 ARCH-03 §8/§9/§10 的每个分支；UI 测试只验证「展示与交互映射」，不重复验证业务规则。

## 3. 领域规则测试矩阵（L1）

### 3.1 今日视图分组

| 用例 | 输入 | 期望 |
| --- | --- | --- |
| 逾期命中 | 昨天到期、todo | `overdue` |
| 逾期 + 等待 | 昨天到期、waiting | `overdue`（带 waiting 徽标），不出现在 waiting |
| 今日到期 | 今天到期、in_progress | `due_today` |
| 今日开始 | 今天开始、todo、下月到期 | `starts_today` |
| 跨天进行中 | 昨天开始、明天到期、in_progress | `in_progress` |
| 进行中无日期 | in_progress、无日期 | `in_progress`，不在 `unscheduled` |
| 等待无日期 | waiting、无日期 | `waiting`，不在 `unscheduled` |
| 未安排 | todo、无日期 | `unscheduled` |
| 明日到期 | 明天到期、todo | `tomorrow` |
| 明日开始但等待中 | 明天开始、waiting | `waiting`（顺序优先） |
| 今日完成 | 今天完成、done | `completed_today` |
| 归档计划任务 | 任意命中条件 | 全部不出现 |
| 去重 | 同时逾期且今天开始 | 只出现一次，在 `overdue` |
| 设置关闭分组 | `today.show_waiting=false` | `waiting` 不展示，计数相应变化 |

### 3.2 进度

| 用例 | 期望 |
| --- | --- |
| 阶段 3 叶子、2 完成 | 66%，`done=2,total=3` |
| 全部完成 | 100%，显示「已完成」 |
| 零任务 | `None`，不显示 100%/0% 进度条 |
| 父任务已完成、子任务未完成 | 进度按叶子计，父任务状态不影响百分比 |
| 计划含未分组任务 | 计入计划进度 |
| 阶段含多层子任务 | 只计叶子，不重复计父任务 |
| 归档后修改任务 | 被拒绝（`E_PLAN_ARCHIVED`），进度不变 |

### 3.3 依赖

| 用例 | 期望 |
| --- | --- |
| 前置未完成 | `is_blocked=true`；开始任务时返回 `W_DEP_INCOMPLETE`，确认后可保存 |
| 前置完成 | 不阻塞 |
| 自依赖 | `E_DEP_SELF` |
| 直接/间接成环 | `E_DEP_CYCLE` |
| 父子依赖 | `E_DEP_ANCESTOR` |
| 跨计划/独立任务 | `E_DEP_CROSS_PLAN` |
| 日期早于前置截止 | `W_DEP_DATE` |
| 删除前置 | 依赖级联删除，后继不再阻塞 |
| 移动到其它计划 | 提示 `W_MOVE_CROSS_PLAN_DEP`，确认后解除 |
| 前置无截止日期 | 不做日期冲突判断 |

### 3.4 日期与状态

| 用例 | 期望 |
| --- | --- |
| `start > due` | `E_DATE_RANGE` |
| 只填开始 / 只填截止 | 合法 |
| 完成 → 重开 | `completed_at` 置空，`status_changed_at` 刷新 |
| 任意状态互转 | 允许，日期不变 |
| 跨午夜 | 逾期集合、今日分组、等待天数更新 |
| 时区改变 | 日期不变，今天按新时区 |
| 夏令时切换日 | 日期加减正确，不出现少一天/多一天 |
| 完成父任务（子未完成） | 需确认，确认后允许 |
| 子任务全部完成 | 不自动完成父任务 |

### 3.5 计划与删除

| 用例 | 期望 |
| --- | --- |
| 归档未完成计划 | 允许，任务从今日/日历消失，日记回顾保留 |
| 恢复归档计划 | 任务重新出现，逾期重算 |
| 删除未归档计划 | `E_PLAN_NOT_ARCHIVED` |
| 删除归档计划 | 级联任务/依赖；小记关联置空 |
| 删除有子任务节点未确认 | `E_HAS_CHILDREN` |
| 删除阶段（保留任务） | 直接子任务移到计划根，子树保留 |
| 删除阶段（级联） | 全部删除 |
| 移动节点到自身后代 | `E_MOVE_INTO_DESCENDANT` |
| 阶段嵌套阶段 | `E_STAGE_CHILD_STAGE` / `E_STAGE_PARENT_INVALID` |

### 3.6 小记与日记

| 用例 | 期望 |
| --- | --- |
| 小记空内容 | `E_NOTE_EMPTY` |
| 小记 20,001 字符 | `E_NOTE_TOO_LONG` |
| 转任务 | 任务标题=首行（≤80），描述=全文，未安排；小记保留关联 |
| 已关联再次转换 | `E_NOTE_ALREADY_CONVERTED` |
| 解除关联 | 任务保留，可再次转换 |
| 删除关联任务 | 小记保留，关联置空 |
| 同日两篇日记 | 更新而非插入 |
| 清空日记后保存 | 删除条目 |
| 日记 50,001 字符 | `E_JOURNAL_TOO_LONG` |

## 4. 存储测试（L2）

| 用例 | 期望 |
| --- | --- |
| 全新库初始化 | `user_version=2`，所有表/索引（含提醒）存在 |
| 重复打开 | 不重复迁移，数据不变 |
| CHECK 约束 | 非法 kind/status/priority/日期顺序被拒绝 |
| 外键级联 | 删除计划/父任务/依赖后无孤儿 |
| 事务回滚 | 移动树中途失败，原树完整 |
| 并发读 | WAL 下读不阻塞写，写不阻塞读 |
| 崩溃恢复 | 强制结束进程后重启，已提交数据存在 |
| 迁移失败 | 原库可用，预迁移备份存在 |
| 高版本库 | 拒绝打开，不修改文件 |
| 唯一约束 | 同日日记、重复依赖、重复小记关联被拒绝 |
| 查询性能 | 1 万任务下今日/月历/计划详情 p95 < 10ms |

**测试数据**

- Fixture 构建器：创建 N 个计划（含阶段/未分组）、M 个任务（含多层子任务、四态、优先级、日期边界）、依赖边、小记、日记。
- 固定时钟：`2026-10-23`（周四）；边界日期：10-22、10-23、10-24、月末、闰年 2-29、跨年。
- 大文本：20,000/50,000 字符边界；含 emoji、中文、换行、CRLF。
- 损坏文件：截断的 SQLite、错误文件头、错误 `app_id`、高 schema 版本。

## 5. 应用集成（L3）

| 用例 | 期望 |
| --- | --- |
| 命令成功 | 事务提交 → 事件 → 查询返回新值 |
| 命令失败 | 回滚、界面数据仍为旧值、无事件 |
| 事件范围 | 任务修改只刷新相关页面；计划归档刷新三处 |
| 详情面板目标被删除 | 关闭面板、Toast、无崩溃 |
| 快速连续修改 | 命令串行、最终一致 |
| 跨页修改 | 今日改日期 → 日历/计划板刷新 |
| 日期滚动 | 跨午夜事件触发今日刷新 |
| 长任务取消 | 取消后无临时文件、无半份数据 |
| 单实例 | 第二进程退出，第一进程被唤醒 |
| 保存失败 | 关闭窗口被阻止并提示 |

## 6. 视图与 UI 测试（L4/L5）

### 6.1 视图模型（L4）

- 今日 DTO → 分组模型：顺序、计数、折叠默认值、空分组隐藏。
- 任务行派生展示：逾期文案、等待天数、优先级颜色语义、计划/阶段徽标、子任务计数。
- 日历 DTO → 月格（6×7、非本月、预览上限 2、+N）、周列（7 日 `DayAgenda`）与共享日期详情；月/周切换保留选日，跨周/跨年与周起始变更正确，无第三种日视图。
- 计划 DTO → 路线图（阶段顺序、缩进、进度、问题定位）。
- 设置 → 控件值/禁用状态/错误文案。
- 空态/错误态/只读态映射。

### 6.2 UI 冒烟（L5）

| 页面 | 检查点 |
| --- | --- |
| 今日 | 快速添加、勾选、分组折叠、打开详情 |
| 日历 | 月/周切换、换月/周、选日详情、独立 Today、月格/周列拖拽（手工） |
| 计划板 | 新建计划、阶段展开、任务树增删、依赖 |
| 小记 | 输入、自动保存、转换 |
| 日记 | 切换日期、自动保存、回顾 |
| 设置 | 主题/密度切换、快捷键录制 |
| 外壳 | 导航、窗口关闭/恢复、详情抽屉焦点 |

- Slint 渲染测试优先使用框架提供的测试接口；若无稳定接口，则以「视图模型断言 + 三平台手工冒烟」替代，并在发布清单中记录。
- 截图对比不作为门禁（字体/渲染差异导致脆弱）。

### 6.3 可访问性与输入

- 全键盘完成核心流程：创建任务 → 改日期 → 完成 → 删除（确认）。
- 焦点顺序、焦点环、Dialog 焦点陷阱、Esc 行为。
- 中文 IME：拼音组合、候选、删除、英文混输；组合期间不触发快捷键。
- 高 DPI（150%/200%）、系统字体缩放。

### 7.1 提醒回归矩阵（v0.2，发布必测）

以可注入 Clock 与平台通知替身测试 [REM-01](../11-reminders/01-reminders-and-notifications.md) 的 `AC-REM-*`，并在上述所有平台安装包执行 SPIKE-07：

- 任务与小记分别单次/每天/每周，绑定唯一、非法时间、分钟边界；提醒不修改任务日期/Today 分组，不向日历添加小记。
- 隐藏驻留/`--hidden` 到时提交，完全退出无通知；启动/唤醒最近 24h 边界汇总、较早 missed，多个错过 occurrence 不通知轰炸。
- DST 缺失/重复时刻、时区变化、时间前跳/回拨、跨日跨年、连续睡眠；重复规则不重复投递也不重开 done 任务。
- 完成/归档暂停、重开不自动恢复、删除级联、转任务不复制；到期领取与编辑/删除竞态、平台回调迟到、领取前后崩溃、去重唯一键与失败降级。
- schema v1→v2 迁移、完整备份两表、恢复基线、JSON v1 兼容与 v2 规则映射；任何恢复/导入不重放历史通知，失败回滚恢复原调度。
- 拒绝权限/重新开启、系统勿扰、Linux 无服务/actions 缺失、点击已删除对象、隐私正文默认；提交成功不误标为用户已读。
- Windows 安装身份、macOS 签名/LSUIElement、Linux X11/Wayland 各自验证；提醒开启仍满足空闲 CPU/内存门限。

## 8. 性能与资源（L7）

| 指标 | 方法 | 阈值 |
| --- | --- | --- |
| 启动到入口 | 打点（进程开始 → 入口首帧） | ≤ 600ms |
| 启动到主窗 | 打点 | ≤ 1.0s |
| 常驻内存 | 10 分钟后 RSS | ≤ 80MB |
| 主窗内存 | 今日 + 1000 任务 | ≤ 130MB |
| 空闲 CPU | 5 分钟均值 | < 0.5% |
| 今日查询 | 1 万任务基准 | p95 < 10ms |
| 月历查询 | 1 万任务 | p95 < 20ms（含组装） |
| 计划详情 | 2,000 任务计划 | p95 < 30ms |
| 列表滚动 | 1,000 行 | 60fps |
| 自动保存延迟 | 输入停止 → 落库 | ≤ 600ms |
| 备份 20MB 库 | 参考机 | ≤ 3s |

- 使用 `criterion` 做领域/仓储基准；启动与内存使用脚本在参考机执行并记录趋势。
- 回归阈值：任一指标较基线恶化 > 20% 需说明并修复，否则阻断发布。

## 9. 数据安全与恢复（L8）

### 9.1 备份/恢复往返

1. 构造完整数据（计划、阶段、多层任务、依赖、小记、日记、设置）。
2. 备份 → 校验文件 → 修改数据 → 恢复 → 重启。
3. 断言：所有实体数量/字段/关系/设置与备份时一致；`schema_version` 正确；无 `-wal` 残留。

### 9.2 导入/导出往返

- 导出 JSON → 在新库导入（替换）→ 与原库逐实体比较（忽略时间戳精度差异）。
- 合并模式：现有数据不变；导入项 ID 全新；父子/计划/依赖/小记关联正确重映射。
- 重复导入同一文件：合并产生新副本（明确预期），替换不重复。
- 非法文件：格式/版本/字段/引用错误均整体拒绝，库不变。
- 取消：无临时文件、无部分数据。

### 9.3 崩溃与损坏

- 写入中断（kill -9 / 任务管理器结束进程）→ 重启后可打开，已提交数据完整。
- 人为截断数据库 → 启动进入恢复引导，不静默重建。
- 磁盘满模拟 → 写失败提示，原数据不丢。
- 只读目录 → 明确错误与解决建议。

## 10. CI 与门禁

| 阶段 | 内容 | 阻断 |
| --- | --- | --- |
| 提交前 | `cargo fmt --check`、`cargo clippy -D warnings` | 是 |
| PR | L1–L4 全平台（Windows/macOS/Linux）、`cargo deny` | 是 |
| 每日 | L5 冒烟、性能基准、依赖漏洞扫描 | 否（告警） |
| 里程碑 | L6 平台矩阵、L7 性能、L8 数据安全 | 是 |
| 发布 | 全部门禁 + 升级迁移 + 三平台安装包冒烟 | 是 |

**代码评审检查**

- 领域规则是否进入 `fastnote-core`，UI 是否复制规则。
- 是否新增未登记的设置键/表/错误码。
- 是否引入网络/遥测/大依赖。
- schema 变更是否附带迁移与迁移测试。
- 用户可见文案是否符合 SHELL-02 §10。

## 11. 缺陷分级

| 级别 | 定义 | 示例 | 发布处理 |
| --- | --- | --- | --- |
| S0 数据丢失/损坏 | 用户数据不可恢复 | 恢复覆盖未备份、迁移丢任务 | 必须修复 |
| S1 核心不可用 | 无法启动/无法创建任务/入口不可用 | 启动崩溃、悬浮球点击无响应 | 必须修复 |
| S2 主要功能错误 | 分组/进度/依赖错误但可绕过 | 今日漏任务、进度算错 | 必须修复 |
| S3 体验缺陷 | 布局、文案、焦点、非关键路径 | 按钮错位、提示不清 | 可带版本修复 |
| S4 建议 | 优化项 | 动画、措辞 | 排期 |

## 12. 验收标准

| 编号 | 验收标准 |

| AC-QA-01 | L1 覆盖 ARCH-03 §8/§9/§10 全部分支，且每个用例可在 CI 稳定运行。 |
