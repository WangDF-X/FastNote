## 1. 目的与范围

定义 FastNote 主窗口的整体框架：侧边导航、页面头部、内容区、全局详情面板、窗口生命周期与页面状态。各功能模块只填充「内容区 + 页面头部」，不重复实现外壳。

**范围内**：信息架构、布局、导航与路由、窗口行为、页面级状态、首次启动、与其他窗口（悬浮球/托盘/快速捕获）的关系。
**范围外**：反馈组件细节与快捷键（SHELL-02）、各模块业务（03–07）、设置项 UI（08）。

---

## 2. 信息架构

```text
FastNote 主窗口
├── 侧边导航
│   ├── 今日任务      （默认）
│   ├── 日历
│   ├── 小记
│   ├── 日记
│   ├── 计划板
│   └── 设置          （底部，独立区域）
├── 内容区
│   ├── 页面头部：标题 / 上下文 / 主操作 / 保存状态
│   └── 页面主体：由各模块填充
└── 全局任务详情面板（右侧抽屉，覆盖在内容区之上）
```

- 五个核心模块 + 设置中心，与 product §3.2 一致。
- 设置中心是独立页面而非弹窗，侧边导航保持不变；返回时回到进入设置前的页面。
- 任务详情面板是**全局唯一**的覆盖层，不改变当前路由。

## 3. 布局规格

### 3.1 主窗口

| 项 | 规格 |
| --- | --- |
| 默认尺寸 | 1280 × 800 逻辑像素 |
| 最小尺寸 | 1024 × 680 |
| 默认位置 | 主屏居中；恢复时使用上次位置并校正到可见工作区 |
| 标题栏 | 原生标题栏，标题固定为 `FastNote` |
| 页面切换 | 即时切换，无转场动画（避免分心与额外重绘） |

### 3.2 侧边导航

| 项 | 规格 |
| --- | --- |
| 宽度 | 208px 固定 |
| 背景 | `bg.canvas`，右侧 1px `border.default` |
| 品牌区 | 高 64，左侧 20 显示应用名 `FastNote`（16px semibold） |
| 导航项 | 高 40，左侧 20；图标 18 + 8 间距 + 文字 14；圆角 8；左右内边距 12 |
| 选中态 | `bg.selected` + `accent` 图标/文字 + 左侧 3px `accent` 竖条（圆角） |
| hover | `bg.hover` |
| 焦点 | 2px `accent` 外框，内缩 2px |
| 今日任务徽标 | 存在逾期任务时，右侧显示红色计数徽标（`danger.subtle` 底 + `danger` 字），最多显示 `99+` |
| 底部设置 | 距离底部 12，与导航项同规格；选中时同样高亮 |
| 折叠 | 第一版不支持折叠（最小窗口宽度下仍保留 208） |

导航项顺序固定：今日任务、日历、小记、日记、计划板；设置位于底部独立区域（上方 1px 分隔线）。

### 3.3 页面头部

| 区域 | 规格 |
| --- | --- |
| 高度 | 64（随内容滚动时吸顶，背景 `bg.canvas` + 底部 1px 分隔） |
| 左侧 | 标题 20/28 semibold；可选副标题 12/16 `text.secondary`（日期、计划名、上下文） |
| 右侧 | 页面级控件（如日期切换、筛选）+ 主操作按钮；元素间距 8 |
| 保存状态 | 文本类页面显示「已保存 14:32」/「保存中…」/「保存失败」；其他页面不显示 |

页面标题与副标题示例：

| 页面 | 标题 | 副标题 |
| --- | --- | --- |
| 今日任务 | 今日任务 | `10月23日 周四` |
| 日历 | 日历 | `2026年10月`（月视图） |
| 小记 | 小记 | `共 128 条` |
| 日记 | 日记 | `10月23日 周四` |
| 计划板 | 计划板 / 计划名称 | `3 个进行中` / `10-01 → 12-31` |
| 设置 | 设置 | 当前分组名 |

### 3.4 内容区

- 左右内边距 24（紧凑 20），底部 24。
- 页面主体独立滚动；头部吸顶；列表分组头吸顶于头部下方。
- 内容最大宽度 1200 居中；列表类页面（今日、计划树）可使用全宽。
- 主操作按钮位于头部右侧；空态中的主操作与头部主操作不重复出现（页面为空时保留头部按钮）。

### 3.5 全局任务详情面板

| 项 | 规格 |
| --- | --- |
| 宽度 | 400px，右侧贴边，全高（头部下方到底部） |
| 形态 | 非模态抽屉，浮于内容区之上，左侧 1px `border.default` + md 阴影；无遮罩 |
| 打开 | 点击任务行 / 计划板任务 / 日历任务 / 日记回顾任务 / Toast 动作 |
| 关闭 | Esc、面板右上角关闭按钮；点击面板外**不关闭**（非模态，允许继续操作列表）；关闭后焦点回到触发元素 |
| 路由 | 不改变当前路由；切换页面时面板关闭 |
| 互斥 | 同一时刻最多一个；打开新任务时替换内容并重置滚动 |
| 内容 | 见 [TODAY-03 任务详情面板](../03-today-tasks/03-task-detail.md) |

> **设计决策 D-23：** 详情面板采用非模态抽屉而非常规弹窗。理由：用户需要边看列表边补全信息（例如对照上下文改日期），模态会打断；同时避免在 Slint 中维护复杂的弹窗焦点栈。

## 4. 导航与路由

### 4.1 路由模型

```rust
pub enum Route {
    Today,
    Calendar { selected: NaiveDate },
    Notes { selected: Option<NoteId> },
    Journal { date: NaiveDate },
    PlanList { tab: PlanTab },
    PlanDetail { plan_id: PlanId, focus: Option<TaskId> },
    Settings { section: SettingsSection },
}
```

- 路由由 `AppController` 持有；UI 不自行维护「当前页」的多个副本。
- 进入设置前记录来源路由；点击侧边栏其它项或「返回」时恢复来源（若来源是计划详情，保留 `plan_id`）。
- 计划详情是独立路由（不是弹窗）；从计划列表进入，面包屑/返回按钮回到计划列表。
- 页面内部状态（滚动位置、选中日期、展开的阶段、列表选中项）在会话内保留；重启不恢复（除设置与窗口位置）。

### 4.2 入口跳转

| 来源 | 行为 |
| --- | --- |
| 悬浮球左键（主窗未打开） | `Today` |
| 悬浮球左键（主窗已打开/隐藏） | 显示并保持当前路由 |
| 悬浮球/托盘菜单「日历」 | `Calendar { selected: today }` |
| 托盘菜单「计划板」 | `PlanList { tab: active }` |
| 全局快捷键「唤起」 | 显示主窗口并聚焦；保持当前路由 |
| 全局快捷键「新建任务」 | `Today` 并聚焦快速添加输入框 |
| 全局快捷键「新建小记」 | 打开快速捕获窗口（不改变主窗口路由） |
| 单实例第二次启动 | 显示主窗口并聚焦当前路由 |
| 开机自启 / `--hidden` | 不显示主窗口，仅常驻入口 |
| 手动启动（无参数） | 显示主窗口，首次启动进入 `Today` |

### 4.3 导航规则

1. 侧边栏点击立即切换；当前项高亮；不产生历史栈（无前进/后退按钮）。
2. 页面内的「查看全部/打开计划」使用显式路由跳转，并在目标页提供返回入口（计划详情 → 计划列表）。
3. 切换页面时关闭详情面板与临时浮层；未提交的标题编辑先失焦提交。
4. 切换页面不重置其他页面的会话状态（例如日历选中日期）。
5. 设置页返回使用「返回」按钮或再次点击来源导航项。

## 5. 窗口生命周期

### 5.1 关闭、最小化、隐藏

| 操作 | 行为 |
| --- | --- |
| 点击窗口关闭按钮 | 按 `general.close_behavior`：`entry`（默认）→ 隐藏主窗口，保留入口；`quit` → 退出应用 |
| 最小化 | 平台默认最小化到任务栏/Dock；应用继续驻留 |
| 从入口/快捷键恢复 | 显示主窗口并聚焦；若之前最小化则恢复 |
| `Primary+W`（macOS 习惯） | 等同关闭按钮 |
| 应用退出（托盘/球菜单/设置） | 冲刷文本、注销快捷键、移除入口、checkpoint、退出 |

- 关闭行为为 `entry` 且入口不可用时（平台能力缺失），自动降级为 `quit` 并提示原因（ARCH-06 §5.5）。
- 隐藏主窗口时停止页面定时器与重绘（ARCH-01 §5.3）；恢复时不重新查询全部数据，仅按 `AppEvent` 失效范围刷新。
- 关闭前不弹「是否保存」：所有编辑自动保存（D-16）；保存失败时阻止关闭并提示。

### 5.2 窗口几何

- 移动/缩放结束后 500ms 防抖写入 `window.main_geometry`（`{x,y,w,h}`）。
- 恢复时校验：目标显示器存在、窗口标题栏可见、宽高不小于最小值；否则居中到主屏并使用默认尺寸。
- 最大化状态不单独存储；恢复时若上次为最大化则最大化显示（geometry 存还原尺寸）。

### 5.3 多窗口关系

| 窗口 | 关系 |
| --- | --- |
| 主窗口 | 唯一；关闭/隐藏不影响入口。 |
| 悬浮球窗口 | 独立置顶小窗；始终存在（球模式）。 |
| 快速捕获窗口（小记） | 独立小窗，置顶、不抢主窗口焦点；同一时刻最多一个；Esc 关闭。 |
| 确认框/日期选择 | 主窗口内浮层，不是独立系统窗口。 |

- 快速捕获窗口与主窗口共享同一服务层；保存后主窗口的小记列表通过 `NotesChanged` 刷新。
- 主窗口未打开时，快速捕获仍可独立工作。

## 6. 页面状态

每个页面必须实现以下状态，避免空白或闪烁：

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| `loading` | 首次查询未返回（>200ms 才显示） | 3 行骨架；头部与导航保持可交互 |
| `ready` | 有数据 | 正常内容 |
| `empty` | 查询成功但无数据 | 页面级空态：图标 + 标题 + 一行说明 + 主操作 |
| `error` | 查询失败 | 页面内错误块：说明 + 「重试」+ 日志 ID（可复制） |
| `read_only` | 数据属于归档计划 | 内容正常 + 顶部只读横幅；编辑控件禁用 |
| `stale` | 事件刷新中 | 保留旧内容，不显示 loading；必要时顶部细进度条（>500ms） |

- 页面切换时若目标页已有会话缓存，先展示缓存再后台刷新，避免骨架闪烁。
- 空态与错误态不得同时出现；错误优先。
- 查询失败不清空已有内容（除非首次加载）。

### 6.1 空态清单

| 页面 | 空态标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 今日任务 | 今天还没有任务 | 在下方输入框快速添加，按 Enter 保存。 | 无（聚焦输入框） |
| 日历（某日） | 这一天还没有安排 | 点击「新建任务」为这一天添加任务。 | 新建任务 |
| 小记 | 还没有小记 | 记录临时想法，之后可以转为任务。 | 写第一条 |
| 日记 | 这一天还没有日记 | 写下今天的进展或感受，内容会自动保存。 | 开始写 |
| 计划板 | 还没有计划 | 把较大的目标拆成阶段和任务，跟踪整体进展。 | 新建计划 |
| 计划详情（无阶段） | 这个计划还没有阶段 | 添加阶段来组织任务，或直接在计划下添加任务。 | 添加阶段 |
| 阶段（无任务） | 这个阶段还没有任务 | 添加第一个任务，或从其它阶段移入。 | 添加任务 |
| 搜索/筛选（如后续） | — | 第一版无搜索。 | — |

## 7. 首次启动

1. 创建数据目录与数据库（ARCH-04），写入默认设置。
2. 按 `general.entry_mode=ball` 创建悬浮球；位置为主屏右下默认位。
3. 显示主窗口并进入 `Today`；`general.first_run_done=true`。
4. 不提供多步引导/示例数据；通过空态文案说明快速添加与快捷键。
5. 首次显示时，悬浮球短暂高亮 1 次（200ms 描边），提示其存在；不重复。
6. 若悬浮球创建失败（平台能力），提示并询问是否切换状态栏模式；两者都失败则保持主窗口并说明。

> **设计决策 D-24：** 不做首次启动向导。产品强调「打开即用」，多步引导会增加负担；入口形态与主题均可在设置中随时修改，默认值已足够合理。

## 8. 与功能模块的契约

外壳向模块提供：

| 能力 | 说明 |
| --- | --- |
| 页面头部插槽 | 标题、副标题、右侧控件、主操作 |
| 内容区容器 | 滚动、内边距、最大宽度、吸顶分组头 |
| 详情面板控制 | `open_task_detail(task_id)` / `close_detail()` |
| 反馈 API | Toast / Dialog / Confirm（SHELL-02） |
| 路由跳转 | `navigate(Route)`，可携带 focus 任务 |
| 当前日期 | 全局 `today`，跨日时刷新 |
| 保存状态 | `set_save_state(Saved/Saving/Failed)` |

模块向外壳提供：

| 能力 | 说明 |
| --- | --- |
| 页面组件 | 由 Slint 组件实现，接收 ViewModel |
| 页面级快捷键处理 | 在获得焦点时处理 Enter/Space/Delete 等（SHELL-02） |
| 查询失效订阅 | 根据 `AppEvent` 刷新自身数据 |
| 路由离开钩子 | 提交未落盘文本、关闭浮层 |

**禁止**

- 模块自绘侧边栏、页面标题、全局遮罩。
- 模块直接创建独立系统窗口（快速捕获除外，由 NOTES 模块定义）。
- 模块修改其它模块的数据模型；统一走命令层。

## 9. 平台差异

| 场景 | Windows/Linux | macOS |
| --- | --- | --- |
| 应用菜单 | 无全局菜单；操作在页面内 | 提供最小应用菜单：关于、设置、隐藏、退出（`⌘Q`）；页面操作仍在页面内 |
| 关闭窗口 | 关闭按钮 → 按设置隐藏/退出 | 同左；`⌘W` 同关闭按钮 |
| 最小化 | 任务栏 | Dock（应用无 Dock 图标时最小化行为由系统处理；主窗口不提供最小化按钮以外的入口） |
| 设置快捷键 | `Ctrl+,` | `⌘,` |
| 窗口菜单 | 无 | 标准 Window 菜单（最小化/缩放） |

- macOS 无 Dock 图标（LSUIElement），用户通过菜单栏图标/悬浮球/全局快捷键重新打开主窗口（ARCH-06 §4.2）。

## 10. 验收标准

| 编号 | 验收标准 |
| --- | --- |
| AC-SHELL-01 | 启动进入今日任务；五个模块与设置均可通过侧边栏到达，当前项高亮正确。 |
| AC-SHELL-02 | 关闭窗口按设置隐藏或退出；隐藏后可通过入口/快捷键恢复且页面状态保留。 |
| AC-SHELL-03 | 窗口位置/尺寸重启后恢复；显示器移除后窗口仍完整可见。 |
| AC-SHELL-04 | 打开任务详情不改变路由；切换页面自动关闭；Esc 关闭并恢复焦点。 |
| AC-SHELL-05 | 每个页面均具备 loading/empty/error/read-only 状态，且切换无白屏闪烁。 |
| AC-SHELL-06 | 归档计划任务在详情中为只读，编辑控件全部禁用并有横幅说明。 |
| AC-SHELL-07 | 首次启动无向导、无示例数据，空态文案可引导完成第一次创建。 |
| AC-SHELL-08 | 今日任务导航项在存在逾期任务时显示正确计数徽标。 |
| AC-SHELL-09 | 窗口宽度 1024 时布局不破版，日历日面板按规范切换为抽屉。 |
| AC-SHELL-10 | 所有页面切换后不残留上一页的浮层、Toast 或详情面板。 |
