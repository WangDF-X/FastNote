## 1. 目的与范围

定义 FastNote 主窗口的整体框架：侧边导航、页面头部、内容区、全局详情面板、窗口生命周期与页面状态。各功能模块只填充「内容区 + 页面头部」，不重复实现外壳。

**范围内**：信息架构、布局、导航与路由、窗口行为、页面级状态、首次启动、与其他窗口（悬浮球/托盘/快速捕获）的关系。
**范围外**：反馈组件细节与快捷键（SHELL-02）、各模块业务（03–07）、设置项 UI（08）。

---

## 2. 信息架构

```text
FastNote 主窗口
├── 侧边导航
│   ├── 今日任务      （默认）
│   ├── 日历
│   ├── 小记
│   ├── 日记
│   ├── 计划板
│   └── 设置          （底部，独立区域）
├── 内容区
│   ├── 页面头部：标题 / 上下文 / 主操作 / 保存状态
│   └── 页面主体：由各模块填充
└── 全局任务详情面板（右侧抽屉，覆盖在内容区之上）
```

- 五个核心模块 + 设置中心，与 product §3.2 一致。
- 设置中心是独立页面而非弹窗，侧边导航保持不变；返回时回到进入设置前的页面。
- 任务详情面板是**全局唯一**的覆盖层，不改变当前路由。

## 3. 布局规格

### 3.1 主窗口

| 项 | 规格 |
| --- | --- |
| 默认尺寸 | 1280 × 800 逻辑像素 |
| 最小尺寸 | 1024 × 680 |
| 默认位置 | 主屏居中；恢复时使用上次位置并校正到可见工作区 |
| 标题栏 | 40px 轻量自绘标题栏，标题固定为 `FastNote`，左侧沿用品牌图标；右侧最小化 / 最大化（还原） / 关闭各 46px，跟随实际应用主题；原生初始化失败时回退原生标题栏 |
| 窗口外沿 | 窗口化使用 Windows 11 原生常规圆角、系统阴影及 1px 中性细描边；最大化时方角、无额外描边或透明留白（D-SHELL-01） |
| 页面切换 | 即时切换，无转场动画（避免分心与额外重绘） |

> **2026-11-03 标题栏修正：** 三个窗口按钮固定锚定右侧，左边界分别为 `width - 138/92/46px`，避免品牌区或弹性布局把按钮挤出窗口；与原生命中测试的右侧 138px 客户区保持一致。标题栏、侧边栏的品牌图片按 SET-02 的实际主题切换现有彩色/反色资产。

> **2026-11-02 用户确认的标题栏策略：** 小开销时采用自绘，大开销时保留原生。当前实现复用 Slint 的按需绘制、winit 无边框阴影与 Win32 原生命中测试，不新增线程、轮询或动效。空白标题栏拖动、双击最大化/还原、右键系统菜单及边缘缩放由 Windows 处理；三个按钮经已有动作入口执行，关闭仍走保存/驻留策略。最大化时关闭缩放热区。Windows 11 最大化按钮悬停的 Snap Layout 浮层不由自绘按钮提供，拖动贴边和 Win+方向键仍使用系统行为。标题栏与内容区同处原有窗口尺寸内，原生还原矩形保存必须区分有/无边框，避免错误扣除标题栏尺寸。

**D-SHELL-01（2026-11-03 用户要求的窗口外沿优化）：** 主窗口需要圆角，窗口化时以阴影或其他轻量效果突出边缘，避免与相近颜色的桌面/窗口混淆。

- Windows 11 通过现有 winit 安全接口请求 `CornerPreference::Round`，让系统裁切整个真实窗口并绘制外部阴影；不使用扩大窗口后的透明留白或额外阴影窗口。系统不支持圆角/原生边框着色时允许保留普通窗口形状，仍有客户区细描边作为边缘反馈。
- 自绘标题栏的窗口化主窗额外绘制 1px 中性外沿，描边圆角 8px，浅/深主题采用 ARCH-05 的 `border.strong`；原生外沿同色。此描边是窗口边界，不是已移除的控件焦点框，不随鼠标点击改变颜色，也不增加交互区域。
- 最大化时请求方角并关闭原生外沿着色描边，客户区细描边隐藏；系统管理阴影在最大化时的收起，不调整窗口客户区尺寸。还原、系统贴边、DPI/主题切换及隐藏重建后重新同步；缓存只记录当前 HWND、实际最大化状态和描边颜色，重建时清空，避免重复原生调用或句柄复用漏设。
- 只影响主窗口，悬浮球及其菜单不改。窗口尺寸/位置记忆、标题栏命中测试、八向缩放、内容布局、快捷键、任务读写与保存/驻留策略不变。
- 不新增依赖、unsafe、线程、轮询、持续动效或背景模糊；复用 Slint 与 winit。真实圆角/阴影、浅深主题和窗口交互由用户手工验收，编译及源码契约测试不能替代外观验收。

## 4. 导航与路由

### 4.1 路由模型

```rust
pub enum Route {
    Today,
    Calendar { selected: NaiveDate },
    Notes { selected: Option<NoteId> },
    Journal { date: NaiveDate },
    PlanList { tab: PlanTab },
    PlanDetail { plan_id: PlanId, focus: Option<TaskId> },
    Settings { section: SettingsSection },
}
```

- 路由由 `AppController` 持有；UI 不自行维护「当前页」的多个副本。
- 进入设置前记录来源路由；点击侧边栏其它项或「返回」时恢复来源（若来源是计划详情，保留 `plan_id`）。
- 计划详情是独立路由（不是弹窗）；从计划列表进入，面包屑/返回按钮回到计划列表。
- 页面内部状态（滚动位置、选中日期、展开的阶段、列表选中项）在会话内保留；重启不恢复（除设置与窗口位置）。

### 4.1.1 本地导航动作与参数（实现契约）

- 格式为 `navigate:<页面名>?key=value&key=value`；这是本地动作字符串，不是 URL，不发起网络请求。保留现有 `navigate:<页面名>` 和 `back`。
- 页面名使用现有中文名称，新增「计划详情」。参数日期为严格的 `YYYY-MM-DD`（1900-01-01–9999-12-31）；实体 ID 为 UUIDv7。可选 ID 用 `none` 表示清空，输出 ID 统一为小写连字符形式。

| 页面名 | 参数 | 示例 |
| --- | --- | --- |
| 今日任务 | 无 | `navigate:今日任务` |
| 日历 | `selected` | `navigate:日历?selected=2026-10-23` |
| 小记 | `selected`（UUIDv7 或 `none`） | `navigate:小记?selected=none` |
| 日记 | `date` | `navigate:日记?date=2026-10-23` |
| 计划板 | `tab`（`active` / `archived`） | `navigate:计划板?tab=archived` |
| 计划详情 | 必需 `plan_id`，可选 `focus`（任务 UUIDv7 或 `none`） | `navigate:计划详情?plan_id=<UUIDv7>&focus=<UUIDv7>` |
| 设置 | `section` | `navigate:设置?section=backup` |

- `SettingsSection` 对应 SET-01 的分组与数据管理子页：`general`（通用与外观）、`hotkeys`（全局快捷键）、`task-preferences`（任务偏好）、`about`（关于）、`storage`（存储位置）、`backup`（备份与恢复）、`import-export`（导入导出）。
- 无参数导航恢复该页最近的会话参数；首次进入日历/日记使用注入的本地今日日期，小记为未选中，计划列表为进行中，设置为通用与外观。有参数导航按参数定位，不替换其他页的会话参数。
- 从设置「返回」恢复完整来源路由；无参数点击来源导航项也恢复来源（包括计划详情的 `plan_id` / `focus`）。在设置内切换分组不覆盖来源。计划详情的 `back` 返回进入详情前的计划列表 Tab，不增加通用历史栈。
- 未知页面、未知/重复/缺失参数、无效日期或 ID 均不改变当前路由，并给出中文错误 Toast；不显示或记录原始动作内容。
- 当前只实现参数定位与占位页面，不查询实体是否存在，也不实现滚动/任务聚焦的业务效果；这些在对应业务模块接入后验收。
- `AppController` 是路由唯一持有者，向 UI 返回页面展示数据及「完整路由是否改变」标记；即使页面名不变，日期/ID/分组参数变化仍算路由变化并清除旧 Toast。

| 错误码 | 条件 | 中文提示 |
| --- | --- | --- |
| `E_ROUTE_TARGET` | 页面名无效 | 无法跳转，目标页面无效。 |
| `E_ROUTE_PARAMETERS` | 参数结构、名称、枚举值无效 | 无法跳转，导航参数无效。 |
| `E_DATE_RANGE` | 日期格式或范围无效 | 无法跳转，日期无效（1900-01-01–9999-12-31）。 |
| `E_ROUTE_ID` | 实体 ID 格式、版本或变体无效 | 无法跳转，内容标识无效。 |

**本次依赖范围**：复用 Cargo.lock 已有版本，日期与 ID 类型位于 core；读取本地今日日期的 `Clock` 实现在 app，不在 core 读取系统时钟。

| 依赖 | 用途 / 启用特性 | 影响与替代方案 |
| --- | --- | --- |
| `uuid` 1.29.0 | UUIDv7 类型及解析；`std` / `v7` | 已有依赖，单个 ID 为 16 字节；复用其解析/版本校验，避免手写 UUID。生成所需随机数依赖由 Cargo 解析，core 本次不生成随机 ID。MIT / Apache-2.0。 |
| `chrono` 0.4.45 | core 仅 `std` 日期类型；app 增加 `clock` | 已有依赖，不引入后台任务；避免手写日历日期与时区转换。MIT / Apache-2.0。 |
| `thiserror` 2.0.21 | ID / 路由错误枚举及错误源链 | 已有传递依赖，改为明确的直接依赖；替代方案为手写 Display/Error，但不符合 AGENTS.md 的错误风格。无新增运行时/常驻任务，体积影响未实测。MIT / Apache-2.0。 |

| --- | --- |

| 手动启动（无参数） | 显示主窗口，首次启动进入 `Today` |

### 4.3 导航规则

1. 侧边栏点击立即切换；当前项高亮；不产生历史栈（无前进/后退按钮）。
2. 页面内的「查看全部/打开计划」使用显式路由跳转，并在目标页提供返回入口（计划详情 → 计划列表）。
3. 切换页面时关闭详情面板与临时浮层；未提交的标题编辑先失焦提交。
4. 切换页面不重置其他页面的会话状态（例如日历选中日期）。
5. 设置页返回使用「返回」按钮或再次点击来源导航项。

## 5. 窗口生命周期

### 5.1 关闭、最小化、隐藏

| 操作 | 行为 |
| --- | --- |
| 点击窗口关闭按钮 | 按 `general.close_behavior`：`entry`（默认）→ 隐藏主窗口，保留入口；`quit` → 退出应用 |
| 最小化 | Windows 球模式：隐藏主窗、从任务栏移除并显示球；托盘模式仍按平台默认最小化到任务栏。其它平台后续实现。 |
| 从入口/快捷键恢复 | 显示主窗口并聚焦；若之前最小化则恢复 |
| `Primary+W`（macOS 习惯） | 等同关闭按钮 |
| 应用退出（托盘/球菜单/设置） | 冲刷文本、注销快捷键、移除入口、checkpoint、退出 |

- 关闭行为为 `entry` 且入口不可用时（平台能力缺失），自动降级为 `quit` 并提示原因（ARCH-06 §5.5）。
- 隐藏主窗口时停止页面定时器与重绘（ARCH-01 §5.3）；恢复时不重新查询全部数据，仅按 `AppEvent` 失效范围刷新。
- 球模式中主窗口与球是同一实体的互斥呈现。系统最小化只切回球，不受 `general.close_behavior=quit` 影响；关闭按钮/`Ctrl+W` 仍遵循关闭设置。创建球失败或保存失败时恢复主窗口并提示，不隐藏到无入口状态。
- 关闭前不弹「是否保存」：所有编辑自动保存（D-16）；保存失败时阻止关闭并提示。

### 5.2 窗口几何

- 移动/缩放结束后 500ms 防抖写入 `window.main_geometry`（`{x,y,w,h,maximized}`）。
- 恢复时校验：目标显示器存在、窗口标题栏可见、宽高不小于最小值；否则居中到主屏并使用默认尺寸。
- 最大化状态存于同一个几何对象的 `maximized` 字段，不另增配置键。保存普通窗口的还原位置/尺寸，最大化、最小化时不覆盖还原矩形；恢复时先设置还原矩形，再应用最大化标记。旧对象缺少该字段时按 `false` 处理。

### 5.4 本轮 Windows 驻留闭环（2026-11-02 已确认）

- 同时实现托盘与悬浮球，默认 `ball`，两者互斥；可在通用设置及入口菜单切换。入口复用已提交的品牌图标，不重新设计/生成图标，也不接入 exe 图标资源。
- 主窗口关闭按钮与 `Ctrl+W` 统一按 `general.close_behavior` 隐藏或退出；隐藏保留当前路由/页面对象，暂停主窗口反馈计时，恢复时解除最小化并请求激活。
- 全局唤起使用 ARCH-04/ARCH-06 已确认的 `Ctrl+Alt+Space`；注册失败显示中文提示，不阻断其它入口。退出移除入口并注销热键，后台设置线程需停止并 join。
- 启动支持手动启动与 `--hidden`；前者显示 Today，后者只显示入口。新建热键、开机自启、单实例、完整设置页、文本编辑冲刷与任务抽屉留给后续模块；本轮不宣称这些验收通过。
- 悬浮球固定 48×48 逻辑像素，透明工具窗口同尺寸，无外部阴影/透明留白；默认主屏工作区右下贴边。拖动松手和恢复旧位置后只贴最近的左/右边，左右等距时左侧优先；纵向保留高度，仅越界夹取，不吸附上下边、不覆盖任务栏。保留 4px 拖动阈值、位置记忆和当前品牌/颜色。不加尺寸控件、半隐藏、额外动效、低电量、跨窗口吸附或全屏检测。
- 手动启动只显示主窗口，球不闪现；`--hidden` 球模式只显示球。点击球、菜单导航或全局唤起时先隐藏球再显示主窗；主窗隐藏/系统最小化后才显示球。托盘图标与主窗仍可共存，托盘模式最小化不变。切换失败先清理目标呈现，再恢复原呈现；失败不丢失原路由或窗口几何。
- 配置唯一事实来源为 ARCH-04 的 SQLite `app_settings`，不创建 `app_meta.json` 配置副本。接入正式 v1→v2 schema 迁移及设置仓储，不实现业务实体增删改。
- 几何保存使用 500ms 防抖；隐藏/退出前提交最终几何。配置写入失败必须提示且不静默改变入口/关闭设置。数据库异常不重建或覆盖原库，主窗口显示错误状态；显式退出时可确认放弃未保存的窗口位置（本轮尚无正文编辑）。
- 保存等待期间若窗口仍被系统移动/最大化，收到提交结果后再次校验并补交最终矩形，不能隐藏时保存过期位置。诊断日志采用已有 `tracing` + 有界后台写入，按日/5MB 滚动并保留 7 天；只写错误码、日志 ID、底层数字码等白名单字段，不写正文或任意 message。
- 文件日志初始化/写入失败时，终端仍输出失败阶段、有效日志/数据库路径、错误类别、底层数字码和日志 ID；设置错误使用与界面相同的日志 ID。路径只在本机终端显示，不进入文件日志；原始错误字符串、SQL、绑定值和正文不得输出。
- 悬浮球的自绘菜单为独立 Slint 工具小窗，按工作区翻转/夹取并在失焦或 Esc 时关闭；本轮透明度固定 90%（hover/press 恢复 100%），不接入闲置效果或其它额外动画。

### 5.3 多窗口关系

| 窗口 | 关系 |
| --- | --- |
| 主窗口 | 唯一；球模式下与球互斥，隐藏保留路由/组件，退出时统一清理。 |
| 悬浮球窗口 | 独立置顶小窗；仅球模式且主窗隐藏时显示，主窗出现时隐藏。 |
| 快速捕获窗口（小记） | 独立小窗，置顶、不抢主窗口焦点；同一时刻最多一个；Esc 关闭。 |
| 确认框/日期选择 | 主窗口内浮层，不是独立系统窗口。 |

- 快速捕获窗口与主窗口共享同一服务层；保存后主窗口的小记列表通过 `NotesChanged` 刷新。
- 主窗口未打开时，快速捕获仍可独立工作。

## 6. 页面状态

每个页面必须实现以下状态，避免空白或闪烁：

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| `loading` | 首次查询未返回（>200ms 才显示） | 3 行骨架；头部与导航保持可交互 |
| `ready` | 有数据 | 正常内容 |
| `empty` | 查询成功但无数据 | 页面级空态：图标 + 标题 + 一行说明 + 主操作 |
| `error` | 查询失败 | 页面内错误块：说明 + 「重试」+ 日志 ID（可复制） |
| `read_only` | 数据属于归档计划 | 内容正常 + 顶部只读横幅；编辑控件禁用 |
| `stale` | 事件刷新中 | 保留旧内容，不显示 loading；必要时顶部细进度条（>500ms） |

- 页面切换时若目标页已有会话缓存，先展示缓存再后台刷新，避免骨架闪烁。
- 空态与错误态不得同时出现；错误优先。
- 查询失败不清空已有内容（除非首次加载）。

### 6.1 空态清单

| 页面 | 空态标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 今日任务 | 今天还没有任务 | 在下方输入框快速添加，按 Enter 保存。 | 无（聚焦输入框） |
| 日历（某日） | 这一天还没有安排 | 点击「新建任务」为这一天添加任务。 | 新建任务 |
| 小记 | 还没有小记 | 记录临时想法，之后可以转为任务。 | 写第一条 |
| 日记 | 这一天还没有日记 | 写下今天的进展或感受，内容会自动保存。 | 开始写 |
| 计划板 | 还没有计划 | 把较大的目标拆成阶段和任务，跟踪整体进展。 | 新建计划 |
| 计划详情（无阶段） | 这个计划还没有阶段 | 添加阶段来组织任务，或直接在计划下添加任务。 | 添加阶段 |
| 阶段（无任务） | 这个阶段还没有任务 | 添加第一个任务，或从其它阶段移入。 | 添加任务 |
| 搜索/筛选（如后续） | — | 第一版无搜索。 | — |

## 7. 首次启动

1. 创建数据目录与数据库（ARCH-04），写入默认设置。
2. 按 `general.entry_mode` 配置入口；球组件与主窗互斥，球首次显示位置为主屏工作区右下贴边。
3. 手动启动显示 `Today` 主窗、球保持隐藏；`--hidden` 只显示入口。首次显示主窗后写入 `general.first_run_done=true`。
4. 不提供多步引导/示例数据；通过空态文案说明快速添加与快捷键。
5. 首次显示时，悬浮球短暂高亮 1 次（200ms 描边），提示其存在；不重复。
6. 若悬浮球创建失败（平台能力），提示并询问是否切换状态栏模式；两者都失败则保持主窗口并说明。

> **设计决策 D-24：** 不做首次启动向导。产品强调「打开即用」，多步引导会增加负担；入口形态与主题均可在设置中随时修改，默认值已足够合理。

## 8. 与功能模块的契约

外壳向模块提供：

| 能力 | 说明 |
| --- | --- |
| 页面头部插槽 | 标题、副标题、右侧控件、主操作 |
| 内容区容器 | 滚动、内边距、最大宽度、吸顶分组头 |
| 详情面板控制 | `open_task_detail(task_id)` / `close_detail()` |
| 反馈 API | Toast / Dialog / Confirm（SHELL-02） |
| 路由跳转 | `navigate(Route)`，可携带 focus 任务 |
| 当前日期 | 全局 `today`，跨日时刷新 |
| 保存状态 | `set_save_state(Saved/Saving/Failed)` |

模块向外壳提供：

| 能力 | 说明 |
| --- | --- |
| 页面组件 | 由 Slint 组件实现，接收 ViewModel |
| 页面级快捷键处理 | 在获得焦点时处理 Enter/Space/Delete 等（SHELL-02） |
| 查询失效订阅 | 根据 `AppEvent` 刷新自身数据 |
| 路由离开钩子 | 提交未落盘文本、关闭浮层 |

**禁止**

- 模块自绘侧边栏、页面标题、全局遮罩。
- 模块直接创建独立系统窗口（快速捕获除外，由 NOTES 模块定义）。
- 模块修改其它模块的数据模型；统一走命令层。

## 9. 平台差异

| 场景 | Windows/Linux | macOS |
| --- | --- | --- |
| 应用菜单 | 无全局菜单；操作在页面内 | 提供最小应用菜单：关于、设置、隐藏、退出（`⌘Q`）；页面操作仍在页面内 |

| 设置快捷键 | `Ctrl+,` | `⌘,` |
| 窗口菜单 | 无 | 标准 Window 菜单（最小化/缩放） |
