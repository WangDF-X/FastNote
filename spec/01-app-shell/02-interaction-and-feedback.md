## 1. 目的与范围

统一定义 Toast、Banner、对话框、字段校验、键盘快捷键、焦点管理与文案规范，确保各模块对同一类事件给出一致的反馈，不出现「有的地方弹窗、有的地方静默」的情况。

**范围内**：反馈层级、组件行为、快捷键表、IME 处理、焦点规则、提醒策略、文案要求。
**范围外**：具体业务提示的触发条件（各模块）、视觉令牌（ARCH-05）。

---

## 2. 反馈层级

| 层级 | 使用场景 | 是否打断 | 是否持久 |
| --- | --- | --- | --- |
| **Inline 字段错误** | 输入不合法、必填缺失 | 否 | 直到修正 |
| **Inline 行内提示** | 依赖阻塞、日期冲突、只读 | 否 | 随状态消失 |
| **Toast** | 操作成功、非阻断失败、可撤销提示 | 否（3–6s） | 否 |
| **Banner** | 需要持续告知的状态（存储异常、只读、能力受限） | 否 | 是，直到解决/关闭 |
| **Dialog** | 破坏性确认、需要明确选择、恢复/导入等重大操作 | 是 | 否 |

**选择规则**

1. 能用 inline 就不用 Toast；能用 Toast 就不用 Dialog。
2. 成功操作：短 Toast（或静默，若结果已在界面明显可见）。
3. 失败操作：保留用户输入 + inline 错误；无法定位到字段时用 Toast（错误）。
4. 破坏性或不可逆：必须 Dialog，且主按钮写明动作。
5. 持续性系统状态：必须 Banner，不能只弹一次 Toast。
6. 不允许静默失败（无任何反馈）或重复提示（同一次操作不超过 1 个 Toast + 1 个字段错误）。

## 3. Toast

### 3.1 规格

| 项 | 值 |
| --- | --- |
| 位置 | 主窗口底部居中，距底 24；详情面板打开时仍居中于内容区（不被面板遮挡，必要时左移面板宽度的一半） |
| 宽度 | 320–420，随文案自适应，最大 420 |
| 结构 | 状态图标 16 + 文案 14 + 可选操作（文字按钮）+ 关闭（×，仅常驻型） |
| 堆叠 | 最多 3 条；新 Toast 在底部，向上堆叠；超出排队 |
| 时长 | 成功 3s / 信息 3s / 警告 5s / 错误 6s；带操作 6s |
| 交互 | hover 暂停计时；点击操作执行并关闭；点击正文不关闭 |
| 焦点 | **不抢焦点**；不进入 Tab 序列（无障碍通过文案播报由平台决定） |
| 去重 | 相同文案 2s 内只显示一条 |

### 3.2 类型与示例

| 类型 | 图标/颜色 | 示例 |
| --- | --- | --- |
| 成功 | 勾 / `success` | 「任务已创建」 |
| 信息 | i / `text.secondary` | 「已切换到状态栏模式」 |
| 警告 | ! / `warning` | 「前置任务尚未完成，已按你的选择开始」 |
| 错误 | ! / `danger` | 「保存失败，请重试」+「重试」 |

**使用示例**

- 快速创建任务成功：**不弹 Toast**（任务已出现在列表，高亮 600ms 即可）。
- 小记转任务成功：Toast「已创建任务」+ 操作「查看」（打开任务详情）。
- 移动任务产生冲突：Toast（警告）「任务已移动，日期超出计划范围」+「查看」。
- 删除成功：Toast「任务已删除」（不提供撤销，第一版无回收站）。
- 快捷键注册失败：错误 Toast，仅启动时一次，详情在设置页。

### 3.3 不允许用 Toast 的场景

- 需要用户选择「继续/取消」的冲突（用 Dialog）。
- 数据损坏、迁移失败（用 Banner + Dialog）。
- 长任务进度（用进度 Dialog）。
- 同一次输入校验（用 inline）。

## 4. Inline 校验与提示

### 4.1 字段校验

- 时机：失焦（blur）与提交时；输入过程中不打断，仅在内容明显超限时提示。
- 呈现：字段下方 12/16 红色文案 + 16px 图标；输入框边框 `danger`。
- 修正后立即清除错误；不清空已输入内容。
- 多个错误：按字段顺序展示，不一次性弹多个 Toast。
- 服务端返回 `Validation` 错误时，映射到对应字段；无字段映射时显示表单级错误块。
- 标题为空：失焦不报错（允许空输入框），提交时提示「请输入任务标题」。

### 4.2 行内状态提示

| 状态 | 呈现 |
| --- | --- |
| 依赖阻塞 | 行内 `⛓` 图标 + tooltip「前置：X 未完成」；详情面板顶部提示条 |
| 日期冲突 | 黄色小图标 + tooltip；详情内文案「开始日期早于前置任务完成日期」 |
| 只读 | 页面/面板顶部中性 Banner「所属计划已归档，仅供查看」 |
| 保存中 | 页面头部「保存中…」（>300ms） |
| 保存失败 | 页面头部红色「保存失败」+ 点击重试；不丢失编辑内容 |

## 5. Banner

| 类型 | 背景 | 图标 | 可关闭 |
| --- | --- | --- | --- |
| Error | `danger.subtle` | `danger` | 否（问题解决后自动消失） |
| Warning | `bg.subtle` + `warning` 文字 | `warning` | 是 |
| Info | `bg.subtle` | `text.secondary` | 是 |
| Read-only | `bg.subtle` | `text.secondary` | 否（状态解除后消失） |

- 位置：页面头部下方、内容区顶部，全宽，高 40，左右内边距 24。
- 结构：图标 + 文案（可含 1 个操作链接）+ 关闭。
- 同一页面最多 1 条 Banner；多条按优先级只显示最高级（error > warning > info > read-only），其余在设置/状态中可查。
- 典型场景：
  - 「数据库文件异常，已切换到只读模式。请从备份恢复。」+「打开数据管理」
  - 「磁盘空间不足，修改可能无法保存。」+「查看存储位置」
  - 「当前桌面环境不支持全局快捷键。」+「了解详情」
  - 「计划已归档，仅供查看。」

## 6. 对话框

### 6.1 规格

| 项 | 值 |
| --- | --- |
| 宽度 | 最大 480，随文案 360–480 |
| 结构 | 标题（动作式）+ 正文（影响说明）+ 可选补充（数量/路径）+ 按钮区 |
| 按钮 | 右下角；取消在左，主操作在右；按钮使用动词（「删除」「归档」「恢复」） |
| 焦点 | 打开时聚焦主按钮（破坏性操作为「取消」）；Tab 在对话框内循环；Esc = 取消 |
| 关闭 | 非破坏性：点击遮罩关闭；破坏性：只能通过按钮或 Esc（等同取消） |
| 并发 | 同一时刻最多一个 Dialog；打开第二个请求排队，不叠加 |
| 嵌套 | 禁止 Dialog 内再开 Dialog（用分步页面替代，如导入预览） |

### 6.2 确认矩阵

| 操作 | 标题 | 正文要点 | 主按钮 | 默认焦点 |
| --- | --- | --- | --- | --- |
| 删除无子任务的任务 | 删除任务？ | 「标题」将被永久删除，无法恢复。 | 删除（danger） | 取消 |
| 删除含子任务的任务 | 删除 N 个任务？ | 包含 N 个子任务，将一并删除且无法恢复。 | 删除（danger） | 取消 |
| 删除阶段（保留任务） | 删除阶段？ | 阶段内 N 个任务将移到计划根，不会被删除。 | 删除阶段 | 取消 |
| 删除阶段（级联） | 删除阶段及 N 个任务？ | 阶段内所有任务将被永久删除。 | 全部删除（danger） | 取消 |
| 归档未完成计划 | 归档计划？ | 仍有 N 个未完成任务；归档后从今日与日历隐藏，数据保留。 | 归档 | 取消 |
| 删除计划 | 永久删除计划？ | 计划及 N 个任务将被删除，无法恢复。 | 永久删除（danger） | 取消 |
| 删除小记 | 删除小记？ | 内容将被永久删除；已转换的任务不受影响。 | 删除 | 取消 |
| 删除日记 | 删除这篇日记？ | 「10月23日」的记录将被永久删除。 | 删除 | 取消 |
| 完成含未完成子任务的任务 | 标记为完成？ | 仍有 N 个子任务未完成；父任务会显示为已完成。 | 仍要完成 | 取消 |
| 开始被阻塞的任务 | 前置任务未完成 | 「X」尚未完成。仍要开始吗？ | 仍要开始 | 取消 |
| 移动导致依赖跨计划 | 解除跨计划依赖？ | 移动后将解除 N 条跨计划依赖，任务日期保持不变。 | 移动并解除 | 取消 |
| 从备份恢复 | 从备份恢复？ | 当前数据将被备份后替换，应用需要重启。 | 恢复并重启 | 取消 |
| 导入并替换 | 替换现有数据？ | 当前全部计划、任务、小记、日记将被导入内容替换。 | 替换 | 取消 |
| 退出应用（仅当保存失败） | 退出 FastNote？ | 有内容尚未保存成功，退出可能丢失。 | 退出 | 取消 |

> **设计决策 D-25：** 删除一律硬删除 + 强确认（D-11）。不提供「不再提示」选项，避免用户关闭安全确认后误删。

### 6.3 快速捕获关闭确认

小记快速捕获窗口中已有内容时关闭：Dialog「保存这条小记？」→「保存并关闭」/「丢弃」/「取消」。空内容直接关闭。

## 7. 键盘快捷键

### 7.1 修饰键约定

- `Primary` = Windows/Linux 的 `Ctrl`，macOS 的 `Cmd`。
- 全局快捷键（系统级）另用 `Ctrl+Alt+…`，见 [ENTRY-03](../02-desktop-entry/03-global-hotkeys.md)。
- 应用内快捷键不可自定义（第一版仅全局快捷键可配置）。

### 7.2 应用级快捷键

| 快捷键 | 行为 | 适用页面 |
| --- | --- | --- |
| `Primary+1` | 今日任务 | 全局 |
| `Primary+2` | 日历 | 全局 |
| `Primary+3` | 小记 | 全局 |
| `Primary+4` | 日记 | 全局 |
| `Primary+5` | 计划板 | 全局 |
| `Primary+,` | 设置 | 全局（macOS 为 `⌘,`） |
| `Primary+N` | 执行当前页面「新建」主操作（见 §7.3） | 全局 |
| `Primary+W` | 关闭主窗口（按设置隐藏/退出） | 全局 |
| `Esc` | 关闭最上层浮层（菜单 → 对话框 → 详情面板 → 关闭选择） | 全局 |
| `Tab` / `Shift+Tab` | 焦点下一个/上一个 | 全局 |
| `Enter` | 激活焦点项（打开任务、提交输入） | 列表/输入 |
| `Space` | 切换焦点任务的完成状态 | 任务列表（非输入态） |
| `Delete` / `Backspace` | 删除焦点任务（弹确认） | 任务列表（非输入态） |
| `↑` / `↓` | 列表焦点上/下移动 | 列表 |
| `Home` / `End` | 列表首个/最后一个 | 列表 |
| `←` / `→` | 计划树折叠/展开；日历中切换选中日 | PLAN / CAL |
| `PageUp` / `PageDown` | 日历上一月/下一月 | CAL |
| `T` | 日历回到今天 | CAL（非输入态） |

### 7.3 `Primary+N` 的页面语义

| 页面 | 行为 |
| --- | --- |
| 今日任务 | 聚焦页面顶部快速添加输入框 |
| 日历 | 聚焦日面板的快速添加；无选中日时选中今天 |
| 小记 | 聚焦小记输入区 |
| 日记 | 聚焦正文编辑器（当天无条目则准备创建） |
| 计划板列表 | 打开「新建计划」对话框（「已归档」Tab 下无操作，不报错） |
| 计划详情 | 在最后选中的阶段末尾展开「添加任务」输入；无阶段时在计划根添加 |
| 设置 | 无操作（快捷键无效，不报错） |

### 7.4 输入与 IME 规则

1. 输入框聚焦时，`Space`、`Enter`、`Delete` 不做全局动作，交给输入框。
2. **中文输入法组合输入期间**（composition active）：
   - 不处理任何单键快捷键（Space/Enter/Esc/Delete/方向键）与 `Primary+字母` 快捷键；
   - `Esc` 交给输入法取消候选，不关闭面板；
   - 组合结束后恢复正常处理。
3. 多行编辑器中 `Enter` 换行，`Primary+Enter` 触发保存（快速捕获/对话框内）。
4. 快捷键冲突：应用内快捷键固定，不做冲突检测；与系统冲突时由系统优先，应用不可见地失效，不提示（仅全局快捷键做冲突处理）。

### 7.5 快捷键提示

- 按钮 tooltip、菜单项右侧显示快捷键（macOS 使用 `⌘`、`⌥`、`⌃`、`⇧` 符号）。
- 空态文案可提示 `Primary+N`。
- 设置页仅展示全局快捷键；应用内快捷键固定展示在「快捷键」页只读列表（便于查找）。

## 8. 焦点与导航

1. 每次页面切换，焦点移到页面标题（不可聚焦时移到第一个可交互项），确保键盘用户知道位置。
2. 打开详情面板：
   - 查看模式：焦点移到面板标题/关闭按钮（Tab 可达字段）；
   - 新建/编辑模式：焦点移到标题输入框。
3. 关闭面板：焦点返回打开它的行/按钮；若该行已被删除，返回列表容器。
4. Dialog：打开时保存原焦点，关闭后恢复；Tab 循环限制在对话框内（焦点陷阱）。
5. Toast/Banner 不抢焦点；Banner 的「重试/查看」可通过 Tab 到达。
6. 列表支持「漫游焦点」（roving tabindex）：Tab 进入列表一次，之后用方向键移动，避免每行都进 Tab 序列。
7. 焦点不可见时不允许吞掉键盘事件；所有快捷键在无焦点上下文时保持全局有效（除输入态）。
8. 鼠标点击与键盘操作结果一致；不设计仅鼠标可用的功能。

## 9. 提醒策略（应用内）

| 提醒 | 触发 | 呈现 | 频率 |
| --- | --- | --- | --- |
| 逾期任务 | 打开主窗口时存在逾期 | 信息 Toast「有 N 个任务已逾期」+「查看逾期」；同时今日导航徽标常驻 | 每个本地自然日最多 1 次 |
| 今日到期 | 打开今日页 | 「今日到期」分组 | 常驻 |
| 依赖未满足 | 开始/完成被阻塞任务时 | Dialog（§6.2） | 每次操作 |
| 计划落后/超期 | 打开计划详情 | 头部健康度徽标 + 问题列表 | 常驻 |
| 日历日过载 | 打开某日面板且 > 8 项 | 日面板轻提示 | 常驻 |
| 存储异常 | 检测到 | Banner | 直到解决 |
| 快捷键注册失败 | 启动/修改时 | 错误 Toast + 设置页 inline | 每次启动最多 1 次 |

- **第一版支持用户主动设置的系统通知**：任务与小记可设置单次、每天或每周提醒；仅应用运行（含隐藏驻留）时调度，启动/唤醒汇总补发最近 24 小时错过的提醒。权限、去重、降级、点击定位见 [REM-01](../11-reminders/01-reminders-and-notifications.md)。不因逾期自动创建系统通知；本节每日逾期 Toast 与定时提醒相互独立。
- Toast 操作「查看逾期」：跳转今日页并滚动到「逾期」分组，分组短暂高亮 600ms。
- 用户关闭 Toast 不影响导航徽标；当天不再重复弹出。

## 10. 文案规范（补充）

| 场景 | 写法 | 避免 |
| --- | --- | --- |
| 成功 | 「已创建任务」「已归档」 | 「操作成功」「OK」 |
| 删除确认 | 「删除任务？」+「『写周报』将被永久删除，无法恢复。」 | 「确定要删除吗？」 |
| 校验 | 「开始日期不能晚于完成日期。」 | 「日期错误」 |
| 阻塞 | 「前置任务『设计评审』尚未完成。」 | 「依赖错误」 |
| 存储 | 「磁盘空间不足，修改可能无法保存。」 | 「IO error」 |
| 权限 | 「当前桌面环境不支持全局快捷键。」 | 「注册失败」 |
| 空态 | 「今天还没有任务。在下方输入框快速添加。」 | 「暂无数据」 |
| 只读 | 「所属计划已归档，仅供查看。」 | 「禁止编辑」 |

- 路径、文件名使用等宽/可复制文本展示；长路径中间省略，hover 显示全路径。
- 数量与单位之间不加空格（3 个任务、5 天）；日期格式见 ARCH-05 §5.7。

## 12. 验收标准

| 编号 | 验收标准 |
| --- | --- |
| AC-SHELL-11 | 同一类成功/失败在各模块的反馈层级一致（不出现某模块用弹窗、另一模块静默）。 |
| AC-SHELL-12 | Toast 最多 3 条、自动消失、hover 暂停、不抢焦点；错误停留 6s。 |
