## 1. 目的与范围

定义日记页面的核心功能：按日查看和编辑个人记录，支持历史日期的浏览与创建。确保用户能够持续、轻松地记录每日的进展或感受。

**范围内**: 日记列表（月份缩略）、日期导航、编辑器布局、自动保存策略、未来/过去日期限制。
**范围外**: 日记回顾与任务链接（DIARY-02）。

**资源生命周期（D-RES-01，2026-11-04 已确认）：** 仅加载当前所选日期正文与所需月份摘要/回顾，不预读全部历史日记。切日期/离开/隐藏先确认保存，长正文与大型编辑模型优先回收；未保存/失败草稿不能因超时或内存压力丢弃。月份、选中日期、滚动/焦点锚点作为轻量会话保留，低成本缓存最多随主窗保留 120 秒；隐藏变化只失效，重开查询不能覆盖保护中的草稿。统一遵循 [ARCH-01 §5](../00-architecture/01-tech-and-runtime.md) / [SHELL-01 §5.5](../01-app-shell/01-overview.md)，本次仅文档确认，实现与资源量测待完成。

## 3. 页面布局

```text
日记
├── ◀ 2026年10月 ▶        [月][周] [今天]  ← 内容内日期导航，无公共模块标题条
├── [今天]                          ← 分组：本地今日（置顶）
│   • 10月23日（周四）    写了一半... │ ← 条目：摘要（前 30 字符）+ 日期
│   
├── [昨日]                          ← 分组：昨天
│   • 10月22日（周三）    完成了...  │
│
├── [10月18日至10月22日]            ← 分组：一周内其他日期
│   ···
│
├── [更早]                          ← 分组：超过一周前的日期
│   ···
└── [+ 新建今日]                     ← 底部按钮（仅当今天无日记时显示）
```

D-SHELL-02 将本地今日日期/周几迁至侧栏；日记历史日期、月/周导航和编辑保存状态仍在内容内，不能用侧栏今日替代。本轮只调整外壳，不实现日记业务。

### 3.1 条目卡片

每个日记条目为一个可点击的卡片：

| 区域 | 内容 |
| --- | --- |
| 左侧 | 日期数字（大字体 24），星期名称（小字 14 secondary） |
| 中间 | 正文摘要（前 30 字符截断 + `…`）；无正文时显示「无正文」 |
| 右侧 | 最后修改时间：今天显示 `HH:mm`；同年非今天显示 `M月D日 HH:mm`；跨年显示 `YYYY年M月D日 HH:mm` |

- 月、周列表的图片计数放在最后修改时间左侧的固定位置，以绿色背景标记（如「2 图」）；没有图片时不显示标记。

- 今天有日记时，其日期用 accent 底色高亮。
- 点击今天及以前已有日记的卡片打开编辑器；未来日期的条目仍显示但不可打开。

## 4. 日期导航

| 操作 | 效果 |
| --- | --- |
| `◀` / `▶` 按钮 | 上一天 / 下一天 |
| `←` / `→` | 上一天 / 下一天 |
| `T` 键 | 回到今天 |
| 点击日历图标 | 弹出日期选择器，选择目标日期 |

### 4.1 视图切换（月 / 周）

顶部导航右侧提供**一个**切换按钮：月视图时显示「周视图」，周视图时显示「月视图」，点击即时切换。

| 视图 | 内容 | 主标签 | 副标签 |
| --- | --- | --- | --- |
| 月视图 | 当前月份的全部日记，按日期倒序，沿用 §3 的分组列表 | 日号（如 `23`） | 星期（如 `周五`） |
| 周视图 | 当前周的 7 天，按周起始日从早到晚排列 | 星期（如 `周五`） | 月/日（如 `11/13`） |

- 切换视图保留锚点日期：月 → 周进入该日所在的周，周 → 月回到该日所在的月。
- 无转场动画，即时切换。
- 两个视图都只显示日记，不读取或标记任务状态。
- 周视图始终显示完整 7 天：今天未写显示「今天还没写」并可点击创建；过去未记录显示「未记录」、未来显示「未到日期」，两者都不可点击。
- 月视图只列出已有日记；整月无日记时显示 §8 空态；周视图不显示空态。

### 4.2 周视图

```text
┌────────────────────────────────────────────────────┐
│ ◀ 2026年第46周 ▶                       [月视图] [今天] │
├────────────────────────────────────────────────────┤
│ ┌────────┬──────────────────────────────┬────────┐ │
│ │ 周一    │ 写了一半...                   │ 14:32  │ │
│ │ 11/9   │                              │        │ │
│ ├────────┼──────────────────────────────┼────────┤ │
│ │ 周二    │ 未记录                        │        │ │
│ │ 11/10  │                              │        │ │
│ └────────┴──────────────────────────────┴────────┘ │
└────────────────────────────────────────────────────┘
```

- 一周起始日跟随设置项 `appearance.week_starts_on`（默认周一，可选周日）。
- 周标题固定格式：`{ISO年}年第{周}周`，例如 `2026年第46周`，不显示日期范围；跨年周使用 ISO 年。
- 标题栏分左右两组：左侧为 `◀ 日期 ▶`（箭头在日期两边），整体靠左；右侧为「视图切换 + 今天」，整体靠右，不居中。
- 日期文本使用**固定 144px 占位**，月视图和周视图保持一致；日期长短变化不会推动左右箭头，切换视图时箭头位置也不变。
- `◀` / `▶` 使用实心箭头图标，与日期文字上下居中。
- `◀` / `▶` 在周视图按 7 天平移，在月视图按自然月平移；日期超出 1900–9999 时忽略该次导航。
- 「今天」保持现有行为：打开今天的日记编辑器；返回列表后显示今天所在的月/周。按钮带边框，悬停时背景变为淡蓝主题色。
- 周序号按 ISO 8601 计算：周一为一周首日，包含 1 月 4 日的那周为第 1 周；跨年周属于其 ISO 年。

## 5. 编辑器模式

点击某日条目后，进入全屏编辑器（覆盖当前列表）：

```text
┌───────────────────────────────────────────┐
│ ← 返回           2026年10月23日 周四     │
├───────────────────────────────────────────┤
│                                           │
│ ┌───────────────────────────────────────┐ │
│ │                                       │ │
│ │          今日进展与感受...             │ │ ← Markdown 源码，自动聚焦
│ │                                       │ │
│ │                                       │ │
│ └───────────────────────────────────────┘ │
│                                           │
│         [已保存 14:32 / 保存中...]        │  ← 状态行
└───────────────────────────────────────────┘
```

- 单栏 Markdown 源码编辑，通过编辑/预览图标在同一内容区切换到渲染预览，不并排显示。
- 预览覆盖小记 §3 已支持的格式（标题、粗体、斜体、删除线、无序/有序列表、任务列表、引用、行内代码、围栏代码块、链接）；不执行内嵌脚本，不加载远程资源。图片和表格不纳入本轮。
- 预览不修改源码；切回编辑后源码逐字不变。
- 最大长度 10000 Unicode 字符。
- 自动保存：编辑停止后 500ms 防抖写入 DB。
- 保存成功时显示「已保存 HH:mm」；如果保存日期不是本地今天，补充日期：同年显示「已保存 M月D日 HH:mm」，跨年显示「已保存 YYYY年M月D日 HH:mm」。保存失败时红色提示 + 重试按钮，保留草稿。
- 只能新建今天的日记；今天及以前已有日记可编辑；过去没有日记的日期和未来日期都不可写（§6）。
- 切换日期、返回列表、离开页面或窗口隐藏前先完成保存；未保存/失败草稿不得丢弃。
- 空正文（`trim` 后为空）且没有图片时不落库：从未输入时关闭不创建条目；已有条目被清空且没有图片时删除该日条目。正文为空但有图片时保留条目。
- `Ctrl+S` 立即保存且不移动输入焦点；`Ctrl+/` 在编辑与预览间切换（与小记一致）。

### 5.1 图片附件（2026-11-10 已确认）

**位置与显示**

- 附件区在正文编辑框下方，不进入 Markdown 正文，也不参与预览解析；编辑和预览两种模式都显示。
- 附件按添加顺序横向排列为缩略图（最长边 480px 的 JPEG），右侧是「添加图片」按钮；没有图片时只显示添加按钮。
- 编辑器底部状态行左侧常驻提示：`图片占用 X MB`（X 为全部日记图片的原图 + 缩略图合计）。
- 列表条目有图片时显示「N 张图片」或摘要后跟「· N 图」。

**添加**

- 只通过 Windows 原生文件选择器添加，一次选择一个文件；首版不支持拖拽、粘贴或拍照导入。
- 仅接受 PNG/JPEG，按文件魔数识别，扩展名不可信；拒绝 SVG/GIF/WebP/HEIC 和伪装扩展名。
- 单张 ≤ 10MB，单张像素 ≤ 4,000 万，单日 ≤ 20 张；超限直接拒绝并说明原因。
- 选中的文件超过 5MB 时先显示「这张图片 N MB，会明显增加数据库和备份体积」并要求确认；确认后才读取和入库。
- 读取、解码、方向校正、缩略图生成全部在 DB 工作线程完成；解码失败提示「图片格式不支持或已损坏」，不写入任何行。
- EXIF 方向在显示时校正，不修改原图字节。
- 新图片追加到末尾，首版不支持拖动排序、裁剪、旋转或编辑。

**查看**

- 点击缩略图打开应用内查看器：深色遮罩、居中显示、适应窗口缩放，标题为「YYYY年M月D日 · 2 / 5」。
- 缩略图右上角在悬停时显示「×」；点击后弹出与查看器一致的删除确认。按钮不改变缩略图尺寸，悬停结束即隐藏。
- 查看器支持左右切换、关闭（按钮或 Esc）和删除；首版不提供缩放、旋转、另存为或外部程序打开。
- 删除需确认；删除最后一张且正文为空时删除该日条目。
- 查看器最多解码到最长边 1600px，关闭即释放；同一时刻只保留一张大图。

**存储与数据管理**

- 原图、缩略图和元数据存入与 `journal_entries` 关联的附件表（ARCH-04 §4.6a），备份 `.fnsbackup` 自动包含图片。
- 删除图片不会立即缩小数据库文件，空间由后续写入复用；设置页「数据占用」显示总大小与文本/图片/其他占比。
- 导出改为 `.fnzip`：`data.json` + `images/<附件ID>.png|jpg`，见 DATA-03；不再输出纯 JSON 的图片数据。

**不支持**

- 内联 Markdown 图片、PDF/文档附件、云端或远程图片、图片链接、图片说明文字。

## 6. 创建新日记

- 只允许创建今天的日记：当天没有日记时，点击「+ 新建今日」或周视图的今天行直接进入空白编辑器。
- 今天及以前**已有日记**的日期可点击编辑；过去没有日记的日期不可补写。
- 未来日期不可创建或编辑；周视图显示「未到日期」，月视图中的未来条目可见但不可打开。
- 首次输入内容或添加图片后才落库；正文为空且没有图片时关闭不创建。

> **设计决策 D-36：** 日记不支持模板或预设内容——第一版保持最小化实现。用户可以通过快速捕获窗口记录临时想法后再整理到日记中。

## 7. 数据模型关联

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| entry_date | TEXT (`YYYY-MM-DD`) | 业务主键，本地日期，唯一 |
| id | TEXT (UUID v7) | 存储主键，仅内部使用，不暴露给界面 |
| content | TEXT | Markdown 源码；无正文且无图片时删除整行，有图片时允许为空 |
| created_at | TEXT (RFC 3339 UTC) | 首次创建时间 |
| updated_at | TEXT (RFC 3339 UTC) | 最后更新时间，用于乐观并发校验 |

> **2026-11-10 已确认（schema v6）：** `journal_entries` 重建为允许空正文；新增 `journal_attachments`（id、entry_date、position、media_type、width、height、byte_size、thumbnail_size、created_at）和 `journal_attachment_data`（attachment_id、bytes、thumbnail）两表，删除日记级联删除附件。完整 DDL 见 [ARCH-04 §4.6a](../00-architecture/04-storage-and-data.md)。
