## 1. 目的与范围

定义日记页面的核心功能：按日查看和编辑个人记录，支持历史日期的浏览与创建。确保用户能够持续、轻松地记录每日的进展或感受。

**范围内**: 日记列表（月份缩略）、日期导航、编辑器布局、自动保存策略、未来/过去日期限制。
**范围外**: 日记回顾与任务链接（DIARY-02）。

## 3. 页面布局

```text
日记
├── 2026年10月                       ← 页面头部副标题
├──                                ← 分隔线
├── [今天]                          ← 分组：本地今日（置顶）
│   • 10月23日（周四）    写了一半... │ ← 条目：摘要（前 30 字符）+ 日期
│   
├── [昨日]                          ← 分组：昨天
│   • 10月22日（周三）    完成了...  │
│
├── [10月18日至10月22日]            ← 分组：一周内其他日期
│   ···
│
├── [更早]                          ← 分组：超过一周前的日期
│   ···
└── [+ 新建今日]                     ← 底部按钮（仅当今天无日记时显示）
```

### 3.1 条目卡片

每个日记条目为一个可点击的卡片：

| 区域 | 内容 |
| --- | --- |
| 左侧 | 日期数字（大字体 24），星期名称（小字 14 secondary） |
| 中间 | 正文摘要（前 30 字符截断 + `…`）；无正文时显示「开始写」 |
| 右侧 | 时间戳（如有）；保存状态（如果编辑中则显示「保存中…」） |

- 今天有日记时，其日期用 accent 底色高亮。
- 点击卡片打开该日的日记编辑器。

## 4. 日期导航

| 操作 | 效果 |
| --- | --- |
| `◀` / `▶` 按钮 | 上一天 / 下一天 |
| `←` / `→` | 上一天 / 下一天 |
| `T` 键 | 回到今天 |
| 点击日历图标 | 弹出日期选择器，选择目标日期 |

### 4.1 月份视图切换

在页面头部点击年月区域时，切换到月份网格视图（类似 CAL-01 的月视图但只显示有日记或有任务的日期格）：

```text
┌─────────────────────────────────────┐
│ ◀ 2026年10月 ▶     [日记][月历]    │
├─────────────────────────────────────┤
│ ┌───┬───┬───┬───┬───┬───┬───┐     │
│ │ · │ ✓ │ D │ D │ ✓ │ · │ · │     │  D=有日记, ✓=只有任务
│ ├───┼───┼───┼───┼───┼───┼───┤     │
│ │ D │ ✓ │ D │ · │ · │ · │ · │     │
│ └───┴───┴───┴───┴───┴───┴───┘     │
└─────────────────────────────────────┘
```

- 点击含日记的日期 → 打开该日日记。
- 点击有任务无日记的日期 → 先创建一个空白日记。

## 5. 编辑器模式

点击某日条目后，进入全屏编辑器（覆盖当前列表）：

```text
┌───────────────────────────────────────────┐
│ ← 返回           2026年10月23日 周四     │
├───────────────────────────────────────────┤
│                                           │
│ ┌───────────────────────────────────────┐ │
│ │                                       │ │
│ │          今日进展与感受...             │ │ ← textarea, 自动聚焦
│ │                                       │ │
│ │                                       │ │
│ └───────────────────────────────────────┘ │
│                                           │
│         [已保存 14:32 / 保存中...]        │  ← 状态行
└───────────────────────────────────────────┘
```

- 单栏文本编辑，不区分段落格式（纯文本）。
- 最大长度 10000 字符。
- 自动保存：编辑停止后 500ms 防抖写入 DB。
- 保存成功时在右下角显示「已保存 HH:mm」。
- 保存失败时红色提示 + 重试按钮。

## 6. 创建新日记

- 当天没有日记时，点击「+ 新建今日」直接进入编辑器。
- 在月视图中点击无日记的日期 → 自动创建一篇空白日记并打开编辑器。
- 首次输入内容后才落库；空内容关闭时不创建。

> **设计决策 D-36：** 日记不支持模板或预设内容——第一版保持最小化实现。用户可以通过快速捕获窗口记录临时想法后再整理到日记中。

## 7. 数据模型关联

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | TEXT (`YYYY-MM-DD`) | 主键，本地日期 |
| content | TEXT | 正文，允许 NULL（未输入时为 null） |
| created_at | TEXT (RFC 3339 UTC) | 首次创建时间 |
| updated_at | TEXT (RFC 3339 UTC) | 最后更新时间 |
