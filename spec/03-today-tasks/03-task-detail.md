## 1. 目的与范围

定义全局唯一任务详情面板（右侧抽屉）的布局、字段编辑、交互行为与平台差异。所有页面（今日、日历、计划板、日记回顾）打开的任务详情共享同一组件和规则，不出现多套 UI。

**范围内**: 面板布局、字段编辑模式、保存策略、关闭机制、只读态。
**范围外**: 阶段管理（PLAN-03）、依赖选择器（PLAN-05）、小记转任务流程（NOTES）。

## 3. 面板布局

### 3.1 整体结构

```text
┌─────────────────────────────┐
│ 返回 ←        × 关闭       │  ← 头部（48px）
├─────────────────────────────┤
│                             │
│ 标题 [_________]           │  ← 标题输入框（可编辑）
│                             │
│ 📅 开始: 2026-10-23   🔘   │  ← 日期行
│ 📆 到期: 2026-10-25   🔘   │
│                            │
│ ⚠ 优先级: [高 ▼]          │  ← 优先级下拉
│                            │
│ 🏷 所属计划: [未安排 ▼]    │  ← 计划归属
│ 📊 进度: 0%                │  ← 进度条（仅有父任务时）
│                            │
│ ▶ 前置依赖: (无)     +     │  ← 依赖区域
│ ▼                          │
│   • [设计评审]             │
│                            │
│ 💬 描述                     │  ← 正文区
│ ┌─────────────────────────┐ │
│ │ 需要准备的资料...         │ │
│ │                         │ │
│ └─────────────────────────┘ │
│                             │
│                            │
└─────────────────────────────┘
```

### 3.2 规格

| 区域 | 规格 |
| --- | --- |
| 宽度 | 400px 固定，右对齐贴边 |
| 高度 | 全高（从头部下方到底部），独立滚动 |
| 形态 | 非模态覆盖层；左侧 1px border.default + md 阴影 |
| 打开时机 | 点击列表中任何任务行 / 计划树任务 / 日历日面板任务 |
| 关闭方式 | Esc / 右上角 × / 切换路由时自动关闭 |

### 3.3 编辑模式 vs 查看模式

| 场景 | 模式 |
| --- | --- |
| 从列表打开已有任务 | 查看模式（字段可读但默认不可编辑；点击后变编辑态） |
| 快速添加后立刻打开 | 编辑模式（标题聚焦，其余字段为空） |
| 计划树中添加的子任务 | 编辑模式 |

在编辑模式中，所有字段均可修改；修改失焦后立即落盘（防抖 500ms）。

## 4. 字段规则

### 4.1 标题

- 文本输入框，最大长度 200 字符。
- 失焦时自动提交到 DB；超过 200 字符截断并 Toast 警告。
- 空标题不允许提交（inline 错误「请输入任务标题」）。

### 4.2 日期

- 开始日期 / 到期日各自独立；均支持设为空。
- 约束：`start_date <= due_date`（两者均非空时）→ 违反时 inline error。
- 日期选择器格式：YYYY-MM-DD；手动输入或点选均可。
- `start_date` 变化可能导致任务在新分组中显示（如从逾期移到明天）。

### 4.3 优先级

- 四级循环：高 / 中 / 低 / 无。
- 以颜色圆圈表示：红 / 黄 / 灰 / 空心圆。
- 修改后立即生效并重新排序当前分组。

### 4.4 所属计划

- 下拉选择器：显示所有活跃计划 +「未安排」。
- 选择计划后，任务同时出现在该计划的树结构中。
- 移动到其他计划时检查依赖兼容性（如果有关联依赖则提示冲突）。

### 4.5 描述

- 多行文本区，最大 2000 字符。
- 第一版作为纯文本回答，不支持 Markdown。

### 4.6 依赖展示

- 列出所有未完成的前置依赖项。
- 显示为可点击链接（打开对应任务的详情面板并关闭当前面板）。
- 被阻塞的任务旁边有 `⛓` 图标 + tooltip「依赖 X 未完成」。

## 5. 保存策略

遵循 **D-16**：关键操作即时生效，文本类编辑 500ms 防抖自动保存。

| 字段类型 | 保存时机 |
| --- | --- |
| 状态切换（完成） | 即时 |
| 标题 | 失焦即保存（500ms 防抖） |
| 日期 | 确认日期选择器后保存 |
| 优先级 | 选择后即时保存 |
| 所属计划 | 选择后即时保存 |
| 描述 | 失焦后 500ms 防抖保存 |

保存中时在字段旁显示「保存中…」标签（>300ms）；失败时红色边框 + Toast 错误。

---

## 6. 只读模式

当任务所属计划为归档状态时：
- 面板顶部显示 Banner：「所属计划已归档，仅供查看」
- 所有编辑控件禁用（灰色背景，不可聚焦）
- 「关闭」按钮仍可点击
