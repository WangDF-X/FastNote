## 1. 目的与范围

定义全局唯一任务详情面板（右侧抽屉）的布局、字段编辑、交互行为与平台差异。所有页面（今日、日历、计划板、日记回顾）打开的任务详情共享同一组件和规则，不出现多套 UI。

**范围内**: 面板布局、字段编辑模式、保存策略、关闭机制、只读态。
**范围外**: 阶段管理（PLAN-03）、依赖选择器（PLAN-05）、小记转任务流程（NOTES）。

## 3. 面板布局

### 3.1 整体结构

```text
┌─────────────────────────────┐
│ 任务详情     已保存   ×关闭 │  ← 头部（56px，D-TODAY-03）
├─────────────────────────────┤
│                             │
│ 标题 [_________]           │  ← 标题输入框（可编辑）
│                             │
│ 📅 开始: 2026-11-03 09:00  │  ← 日期时间选择入口
│ 📆 到期: 2026-11-03 15:30  │
│                            │
│ 🏷 所属计划: [未安排 ▼]    │  ← 计划归属
│ 子任务: 0/3                │  ← 直接子任务完成数（后续任务树接入）
│                            │
│ ▶ 前置依赖: (无)     +     │  ← 依赖区域
│ ▼                          │
│   • [设计评审]             │
│                            │
│ 💬 描述                     │  ← 正文区
│ ┌─────────────────────────┐ │
│ │ 需要准备的资料...         │ │
│ │                         │ │
│ └─────────────────────────┘ │
│                             │
│                            │
└─────────────────────────────┘
```

### 3.2 规格

| 区域 | 规格 |
| --- | --- |
| 宽度 | 400px 固定，右对齐贴边 |
| 头部 | 56px；图标、任务详情标题、保存状态和关闭按钮垂直居中 |
| 高度 | 全高（从头部下方到底部），独立滚动 |
| 形态 | 非模态覆盖层；左侧 1px border.default + md 阴影 |
| 打开时机 | 点击列表中任何任务行 / 计划树任务 / 日历日面板任务 |
| 关闭方式 | Esc / 右上角 × / 点击详情外部 / 切换路由；先保存成功再关闭 |

### 3.3 编辑模式 vs 查看模式

| 场景 | 模式 |
| --- | --- |
| 从列表打开已有任务 | 字段可直接编辑；归档计划任务只读 |
| 快速添加 | 标题唯一必填，成功后清空快速添加框并保持焦点，不强制打开抽屉 |
| 计划树中添加的子任务 | 编辑模式 |

文本输入 500ms 防抖，失焦提交；日期时间组合确认后保存。状态与优先级在任务行编辑，不在共享详情重复提供入口。本轮计划/父级/依赖只展示已有信息，不提供尚未实现的选择器。

## 4. 字段规则

### 4.1 标题

- 文本输入框，最大长度 200 字符。
- 超过 200 字符返回 `E_TITLE_TOO_LONG` 并保留输入，不静默截断。
- 空标题不允许提交（inline 错误「请输入任务标题」）。

### 4.2 日期时间

- 开始 / 到期各自独立；使用日历和时分选择组件，不要求手动输入；24 小时制，精确到分钟，展示 `YYYY-MM-DD HH:MM`。
- 所选日期和时间作为一组确认，不能因为只选择日期就提交暂时的半成品；取消选择不修改原值。提供清除入口，同时清除该字段的日期和时间。
- 未设置时选择器预填设备本地当前日期和时分，已有值预填自身值；预填不等于保存。
- 约束：开始不能晚于到期；同一天且双方均有时间时比较时分，违反时就近报错并保留草稿。
- 旧任务的 date-only 排期保留为全天，不自动补写时分；日期时间未重新确认前不会改变旧内容。全天开始视为当天起点，全天到期到次日才逾期。
- 新选择的到期时分超过后即进入「逾期」，不等次日；开始时间不产生逾期，不自动切状态，也不创建提醒。
- 开始变化按八组规则重算；仅改变开始日期不能消除由过去到期日产生的逾期。

### 4.3 状态与优先级入口

- 任务行状态下拉包含待处理、进行中、等待中、已完成；优先级按钮循环高 / 中 / 低 / 无。
- 共享详情不再提供这两项的编辑控件，避免入口重复；领域命令仍统一处理状态、完成时间和排序。

### 4.4 所属计划

- 下拉选择器：显示所有活跃计划 +「未安排」。
- 选择计划后，任务同时出现在该计划的树结构中。
- 移动到其他计划时检查依赖兼容性（如果有关联依赖则提示冲突）。

### 4.5 描述

- 多行纯文本区，最大 10,000 字符，超限保留草稿并拒绝提交。
- 第一版作为纯文本编辑，不支持 Markdown。

### 4.6 依赖展示

- 列出所有未完成的前置依赖项。
- 显示为可点击链接（打开对应任务的详情面板并关闭当前面板）。
- 被阻塞的任务旁边有 `⛓` 图标 + tooltip「依赖 X 未完成」。

## 5. 保存策略

遵循 **D-16**：关键操作即时生效，文本类编辑 500ms 防抖自动保存。

| 字段类型 | 保存时机 |
| --- | --- |
| 状态切换（完成） | 即时 |
| 标题 | 失焦即保存（500ms 防抖） |
| 日期时间 | 日期和时分组合确认后保存；清除同时提交二者 |
| 优先级 | 任务行按钮点击后即时保存 |
| 所属计划 | 选择后即时保存 |
| 描述 | 输入停止 500ms 或失焦时保存 |

保存中时在字段旁显示「保存中…」标签（>300ms）；失败时红色边框 + Toast 错误。

- 查询/保存只替换已确认的数据库快照；旧回包不能覆盖用户之后输入的新草稿。
- 打开另一任务、关闭面板、切页、隐藏和退出前提交最新草稿；失败或非法输入保留当前编辑并提示，不静默关闭。显式退出时可通过破坏性确认放弃未保存输入，默认取消。
- 仓储写入使用事务和版本冲突检查，数据库变更事件到达后再重查列表/详情。
- 点击详情外部的首次点击只触发保存关闭，不穿透执行底层按钮，避免保存过程中误删或重复打开任务。日期/时间弹层属于详情内部；弹层选择、取消及状态确认对话框不能误触发详情关闭。

## 6. 只读模式

当任务所属计划为归档状态时：
- 面板顶部显示 Banner：「所属计划已归档，仅供查看」
- 所有编辑控件禁用（灰色背景，不可聚焦）
- 「关闭」按钮仍可点击

### 8.2 日期弹层与文字/图标统一（D-TODAY-03，2026-11-03）

用户确认功能可用并授权 UI 优化。日期时间改为同一 320×432px 紧凑弹层，使用六周小月历与同风格年/月/时分下拉；组合确认/取消语义不变，重新打开恢复当前字段值和所选项的滚动位置。详情沿用 400px 宽度，头部 56px；标题、输入、字段标签、辅助说明遵循 ARCH-05 共享字号，日期入口、清除、重试、删除等具备统一图标。只读、非法日期保留草稿和外部点击保存关闭等规则不变，无新增待确认项。字体图标、弹层尺寸、浅深主题及鼠标/键盘交互仍由用户手工验收，不以编译和源码契约检查代替。

下拉的鼠标、键盘与无障碍选择统一在弹层仍存活时回传索引，随后关闭菜单；日期时间「应用」先冻结并回传日期/时分组合值，再关闭弹层。不得先销毁弹层再调用依赖其父组件的回调；取消、Esc 和外部点击关闭选择弹层均不提交临时选择。

### 8.3 常驻文字精简（D-TODAY-04，2026-11-03 用户要求）

删除「自动保存 · 点击详情外部，保存后关闭」及日期时间选择教学说明。日期字段标签简化为「开始时间」「到期时间」，输入占位简短；弹层底部仅保留待应用的日期与时分预览。保存状态、只读说明、错误文案、重试和删除确认等必要反馈不删除，原有确认/取消与保存保护不变。

### 8.4 日期显示与中性文字（D-TODAY-05，2026-11-03 用户要求）

详情日期按钮及弹层预览与列表统一：当年显示 `MM-DD`，非当年显示 `YYYY-MM-DD`，时分精度不变。显示文本不得回写日期草稿，年份编辑和无障碍说明保留完整日期。删除入口文字保持中性色，仅图标表达危险色；原有错误反馈、删除确认和保存保护不变。

### 8.5 年月选择与初始焦点（D-TODAY-06，2026-11-03 用户反馈）

年份下拉仅列 2000–2100，默认聚焦已有年份并保证选中项可见。年月切换和月份箭头同时更新待应用日期，保留日与时分，月底超出时向下校正；不再只改变浏览月份。确认/取消和保存失败保留草稿的规则不变。限制不追溯改写旧日期，范围外旧年份仅将浏览位置靠近允许范围，不修改原组合值。
