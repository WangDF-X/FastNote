## 1. 目的与范围

定义用户在今日任务页面对单个任务和批量任务的交互操作：完成/撤销、删除、修改日期/优先级、移动到其他分组，以及对应的反馈机制（Toast/Dialog/inline）。确保所有操作结果一致且可感知。

**范围内**: 单个任务操作、键盘快捷键（Space/Delete）、确认框矩阵的 Today 相关条目。
**范围外**: 依赖管理（PLAN-05）、批量改期（v2 不在 v1 中）、树级拖拽（PLAN-04）。

## 3. 页面内单行操作

### 3.1 完成 / 撤销完成

| 操作方式 | 行为 |
| --- | --- |
| 鼠标左键点击任务行的「完成」圆形复选框 | 未完成 → done；done → todo；成功后按四区规则重查 |
| `Space`（任务行聚焦时） | 同左键点击 |
| 保存成功后 Toast「已完成」或「任务已重新打开」 | 完成项进入「今日完成」，不硬删除 |

> **设计决策 D-34（2026-11-08 同步）：** 今日完成默认折叠，可展开重开；三态在任务行任意直接切换，日期不随状态改变。离开 done 清空完成时间，任意真实状态变化更新状态变更时间；重复设置相同状态不改历史时间。

> **D-TODAY-02 / D-TODAY-09：** 任务行右侧固定顺序为「状态下拉 → 设置日期 → 优先级循环按钮 → 删除按钮」。状态下拉只含未开始、进行中、已完成，保存失败恢复数据库状态；不保留重复的只读状态徽标。左侧完成/重开入口保留，日期/风险独立展示。共享详情不重复状态和优先级编辑控件。

### 3.2 删除任务

触发场景：
- 键盘：选中任务后按 `Delete`
- 鼠标：点击行右侧删除按钮

行为：
1. 弹出 Dialog（§6.2 of SHELL-02）：
   - 无子任务 → 「删除任务？」→ 永久删除
   - 有子任务 → 「删除 N 个任务？」→ 包含子任务数
2. 确认后执行删除命令 → Toast「任务已删除」。
3. 如果当前正在详情面板中编辑被删任务 → 面板关闭并 Toast。

### 3.3 修改日期

点击任务行日期标签打开共享详情，按 TODAY-03 编辑；本轮不重复实现行内日期编辑器。

| 操作 | 效果 |
| --- | --- |
| 点击开始日期 → 日期选择器（年/月/日） | 修改 start_date |
| 点击到期日 → 日期选择器 | 修改 due_date |
| 开始和到期均清空 | 未开始进入待安排；进行中仍在当前关注，完成项按本地完成日归类 |

日期和时分均使用选择组件，24 小时制、分钟精度；日期时间组合确认后提交，取消不改原值。详见 TODAY-03 §4.2。

> **设计决策 D-35：** 不引入拖拽改日期的快捷操作（CAL-02 中的 alt-drag 也排除）。

### 3.4 修改优先级

点击任务行上的优先级徽标（红/黄/灰圆圈），循环切换：高 → 中 → 低 → 无。每次切换后立即生效并刷新排序。

## 4. 键盘快捷键（Today 专属）

| 快捷键 | 行为 |
| --- | --- |
| `Space` | 切换选中任务的完成状态 |
| `Delete` / `Backspace` | 删除选中任务（弹确认 Dialog） |
| `↑` / `↓` | 列表中焦点上/下移动 |
| `Tab` | 跳到快速添加输入框（如果不在焦点区） |
| `Enter` | 打开任务详情面板（非输入态） |
| `Escape` | 关闭任何打开的浮层/面板；快速添加时清空输入并移除焦点 |

## 5. 反馈与时序

| 动作 | UI 反馈 | 备注 |
| --- | --- | --- |
| 完成 | 行淡出 + Toast | 淡出动画 200ms |
| 重开（今日已完成组或详情） | 按当前状态/日期重新分组 | done → todo，清空 completed_at |
| 创建 | 新行出现 + 边框高亮 600ms | 不弹 Toast |
| 删除 | 行消失 + Toast | — |
| 改日期 | 该行所属分组可能变化 → 旧分组更新，新分组插入 | — |
| 改优先级 | 立即重排序 | — |
| 操作失败 | Toast 错误 + inline（如适用） | — |
