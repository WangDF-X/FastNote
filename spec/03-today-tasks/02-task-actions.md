## 1. 目的与范围

定义用户在今日任务页面对单个任务和批量任务的交互操作：完成/撤销、删除、修改日期/优先级、移动到其他分组，以及对应的反馈机制（Toast/Dialog/inline）。确保所有操作结果一致且可感知。

**范围内**: 单个任务操作、键盘快捷键（Space/Delete）、确认框矩阵的 Today 相关条目。
**范围外**: 依赖管理（PLAN-05）、批量改期（v2 不在 v1 中）、树级拖拽（PLAN-04）。

## 3. 页面内单行操作

### 3.1 完成 / 撤销完成

| 操作方式 | 行为 |
| --- | --- |
| 鼠标左键点击任务行的「完成」圆形复选框 | 切换完成状态；从 Today 列表中消失（移至已完成，不再显示） |
| `Space`（任务行聚焦时） | 同左键点击 |
| 点击后 → Toast「已完成」（2s 信息提示，可选「撤销」） | — |

> **设计决策 D-34：** 第一版不提供回收站或「已完成」列表在 Today 页面中查看；已完成的任务直接进入历史。

### 3.2 删除任务

触发场景：
- 键盘：选中任务后按 `Delete`
- 鼠标：点击行右侧「⋮」更多菜单 → 「删除」

行为：
1. 弹出 Dialog（§6.2 of SHELL-02）：
   - 无子任务 → 「删除任务？」→ 永久删除
   - 有子任务 → 「删除 N 个任务？」→ 包含子任务数
2. 确认后执行删除命令 → Toast「任务已删除」。
3. 如果当前正在详情面板中编辑被删任务 → 面板关闭并 Toast。

### 3.3 修改日期

通过点击任务行上的日期标签进入修改：

| 操作 | 效果 |
| --- | --- |
| 点击开始日期 → 日期选择器（年/月/日） | 修改 start_date |
| 点击到期日 → 日期选择器 | 修改 due_date |
| 设置为空 → 任务移入「未安排」组 | — |

日期选择器：输入 YYYY-MM-DD 格式，支持 Tab 跳格；Enter 保存，Esc 取消。

> **设计决策 D-35：** 不引入拖拽改日期的快捷操作（CAL-02 中的 alt-drag 也排除）。

### 3.4 修改优先级

点击任务行上的优先级徽标（红/黄/灰圆圈），循环切换：高 → 中 → 低 → 无。每次切换后立即生效并刷新排序。

## 4. 键盘快捷键（Today 专属）

| 快捷键 | 行为 |
| --- | --- |
| `Space` | 切换选中任务的完成状态 |
| `Delete` / `Backspace` | 删除选中任务（弹确认 Dialog） |
| `↑` / `↓` | 列表中焦点上/下移动 |
| `Tab` | 跳到快速添加输入框（如果不在焦点区） |
| `Enter` | 打开任务详情面板（非输入态） |
| `Escape` | 关闭任何打开的浮层/面板；快速添加时清空输入并移除焦点 |

## 5. 反馈与时序

| 动作 | UI 反馈 | 备注 |
| --- | --- | --- |
| 完成 | 行淡出 + Toast | 淡出动画 200ms |
| 撤销完成（从 Toast） | 行从已完成区域回到 Today | 实际 v1 无已完成视图，此操作暂不可用 |
| 创建 | 新行出现 + 边框高亮 600ms | 不弹 Toast |
| 删除 | 行消失 + Toast | — |
| 改日期 | 该行所属分组可能变化 → 旧分组更新，新分组插入 | — |
| 改优先级 | 立即重排序 | — |
| 操作失败 | Toast 错误 + inline（如适用） | — |
